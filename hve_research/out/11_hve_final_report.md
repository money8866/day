# HVE-Research V1 — 标志性高量事件（HVE）→ 事件后路径 → HVT-BULL / W7 二次突破 统一研究

**研究类型**：Event Study + 状态转移 + OOS 交易验证
**样本区间**：2021-01-04 ~ 2026-09-30（1,334 个交易日，可投池口径）
**回测口径**：收盘价成交，T+k 为个股自身交易日；已做后复权；全部特征严格无未来函数
**IS / OOS 切分**：IS = trade_date ≤ 2023-06-30；OOS = trade_date > 2023-06-30
**结论日期**：2026-09-30
**报告性质**：个股/策略的量化研究记录，**不构成投资建议**

| **实盘配置 `config.yaml` 复刻**（§15 新增） | **REJECTED** | 母事件（HVT-A\|B）OOS T+10 波动配对 α = **-1.07%**，p=1.000；**涨幅结构 gain_structure 是减分项**（Δ均值 -0.30pp，三个子条件全负）；仅 price_strength 与 chip_lock 为正增量 |

### 最终裁定

> **NO TRADING AUTHORIZATION**
> 不进入 Paper Trading / 小资金实盘验证阶段。

四条否决理由（任何一条单独都足以否决）：

1. **成本不耐** — OOS T+10 的 α ≈ +26bp，扣除 30bp 往返成本后 α ≈ **-3bp**。仅在 T+3/T+5 残留薄利（+40bp / +13bp）。
2. **尾部依赖** — 剔除收益最高的 5% 样本后，策略均值由 +0.77% 变为 **-1.36%**，PF 由 1.20 降至 0.66；Top5% 贡献了 269% 的总收益。
3. **时间不稳定** — 6 个年度中 2023（α -0.78%）、2026（α -0.25%）显著为负；分板块中**科创板失效**（α -0.28%，p=0.935）。
4. **胜率低于 50%** — 全样本胜率 44.8%，收益中位数 -0.89%。这是"低命中率 + 右尾"型结构，对资金曲线与执行纪律要求极高。

## 1. 数据、样本与口径

### 1.1 面板构建（无未来函数）

| 项目 | 内容 |
|---|---|
| 数据源 | 本地 Tushare 缓存 `cache_daily/stock_data.db`（daily_cache / daily_basic_cache / index_daily_cache） |
| 行数 | 7,119,601（5,780 只股票） |
| 板块 | 主板 3,366 / 创业板 1,442 / 科创板 621 / 北交所 351（**北交所已剔除**） |
| 价格 | 后复权：`adj_close = close_raw × 累计(1+pct_chg)`；tushare `pre_close` 已除权，故 `pct_chg` 即为全收益日收益率（已对 600036.SH / 000651.SZ / 600519.SH 及 4,036 个除权日验证） |
| 滚动特征 | 严格区分"不含当日"（`rmean_prev` / `rmax_prev` / `rmin_prev`）与"含当日"（`rmean_incl` / `rstd_incl`）；秩百分位 `roll_pct` 窗口 250 日、最少 60 个观测，窗口内**仅用历史数据** |
| 剔除规则 | ST/*ST、退市、北交所、上市观测不足 60 日、数据缺失、观察窗不足 |

### 1.2 幸存者偏差：**风险 HIGH**

数据库 5,780 只股票中仅 **11 只**为退市股 —— 样本实质上是"截至 2026-09 仍在市"的截面。
**方向性说明**：幸存者偏差会**系统性高估**策略收益。本研究的结论（多数路径无 α）因此在方向上偏保守；唯一被判定为 SUPPORTED 的 W7 路径，其真实 α 只能比本文所测**更低**。

### 1.3 基准构造（关键方法论）

A 股全市场等权日收益的**均值**为 +0.055%/日（年化 ≈ +14%，样本累计 +78.7%），但**中位数**为 **-0.167%/日**（累计 -90.7%）。均值被极右尾完全主导。

因此本文同时报告两套基准：
- `mkt_fwd_h`：可投池等权**均值**收益的复利链（宽松基准）
- `mktmed_fwd_h`：可投池**中位数**收益的复利链（严格基准，几乎所有策略在此基准下均为负）

另有**同日配对随机重抽样**（Same-day Matched Null）：在每个事件的**同一交易日**、按**波动率十分位**配对随机抽取股票，重复 200~400 次得经验 p 值。这是本文判定 α 的主标准。

## 4. 研究三/四：增量模型、W7 与 Entry 对比

### 4.1 ⚠ 方法论修正（本报告最重要的内部发现）

初版使用 `contr = min(vrp[T+1..T+10]) ≤ 0.5` 作为缩量条件。**该定义对"突破日入场"（突破可能发生在 T+3）构成未来函数**：入场时尚未观测到 T+4..T+10 的成交量。

修正：Entry 在 T+d 时，缩量条件只用 **T+1..T+d-1** 的量能（入场前已知），且要求 d ≥ 3。

**该修正使结论发生反转**，下表左列为修正后（有效），右列为修正前（含未来函数，**已废弃**）：

| 策略 | 清洁版 OOS T+10 | 污染版 OOS T+10 |
|---|---|---|
| W7 突破日入场（含缩量） | **+0.77% / PF 1.20** | -0.76% / PF 0.84 |
| 再扩张日入场（含缩量） | **+0.48% / PF 1.12** | -1.01% / PF 0.79 |
| 有缩量 vs 无缩量（Welch） | **t=+4.10, p=0.00004（缩量优）** | t=-22.1, p<1e-10（缩量劣） |

> ethodological 教训：**"看起来最漂亮的结果"往往是未来函数。** 污染版中"T+S+无缩量 → 事件日入场"给出 +10.27%/PF 9.48 的荒谬高收益，即为典型症状。

## 10. 六个核心问题的回答

**Q1：什么是真正的标志性高量事件？**
量能阈值本身不是"标志性"，**"量能簇的首日"才是**。vr20≥2.0 且为量能簇（gap 5 日内）首日，是唯一稳健的 HVE 定义；簇内最大量日是反向信号（-2.57%）。价格/结构附加条件（涨幅、收盘位置、MA 位置）均不改善、多数恶化。

**Q2：HVE 后是否存在稳定的"缩量→再扩张→突破"路径？**
路径**存在但无稳定的正向预测力**。状态分类中 FAIL（深跌）反弹最强，BULL（延续）不占优 —— 更像均值回归而非路径延续。缩量条件的作用不是"识别路径"，而是"剔除衰竭型突破"（无缩量组 -0.57% vs 有缩量组 +0.78%）。

**Q3：HVT-BULL 的条件中哪些真正增加 α？**
**没有。** M0→M1(+Trend)→M2(+Structure) 单调下降（+0.86%→+0.34%→+0.52%），且同日配对 p=1.000。价格强度、MA 位置、斜率等 HVT-BULL 核心条件在本样本中**均为损耗项**。

**Q4：W7 的"缩量"与"二次突破"哪一个是 α 来源？**
**两者的交互**是 α 来源，但主要贡献来自"突破日入场时点 + 缩量筛选"的组合：单独突破不缩量 +0.16%（无 α），单独缩量不突破 +0.34%（无 α），组合 +0.77%（α +26bp，p=0.000）。**缩量是放大器，不是发生器。**

**Q5：突破当日买入是否比提前潜伏有更好的风险收益结构？**
**是，但优势有限。** 可实施口径下：等突破 +0.77%/PF1.20 vs 固定 T+10 潜伏 +0.34%/PF1.10。但两者均低于"事件日直接买入"(+0.86%/PF1.24)，说明**等待本身在损耗收益，只是损耗小于"潜伏在无缩量样本上"**。
⛔ 名义上最优的"突破前 3~5 日潜伏"（+8.5%~9.6%，PF 10.9~21.3）经审计为未来函数，**不可交易**。

**Q6：HVT-BULL 与 W7 是否为同一母事件的两条路径？**
**不是。** 若真是同一母事件的两条路径，母事件本身应带正 α。实测：母事件（HVE）在同日配对下 **p=1.000、α 为负**；而两条"子路径"的增量方向相反 —— HVT-BULL 式的趋势/结构筛选**减分**，W7 式的缩量+突破**加分**。
**更准确的表述**：HVE 是一个**必要但不充分**的"定位器"（用于缩小观察范围），真正的 α 来自"事件后缩量消化 + 二次突破的入场时点"，而不是高量事件本身。

## 12. 最终裁定

# NO TRADING AUTHORIZATION

不进入 Paper Trading / 小资金实盘验证。

**理由（完整版）**

1. 唯一统计显著的正 α（W7 清洁版，OOS T+10 α = +26bp，p<0.005）**不足以覆盖 30bp 的往返交易成本**（净 α ≈ -3bp）。
2. 该 α **完全依赖最右侧 5% 的样本**（贡献 269% 总收益），剔除后为 -1.36%/PF 0.66 —— 属于典型的"尾部赌博"结构，而非可复制的统计规律。
3. 胜率仅 44.8%、收益中位数 -0.89%，**对执行纪律、仓位与止损的依赖极高**，任何执行偏差都会把正 α 打成负。
4. **时间稳定性不足**：6 个年度中 2 年显著为负（2023 α -0.78%、2026 α -0.25%）；分板块中科创板失效。
5. **可实施性损耗**：17% 的突破日收盘涨停无法成交，剔除后 α 降至约 +22bp。
6. **幸存者偏差风险 HIGH**：样本几乎不含退市股，真实 α 只会更低。
7. HVT-BULL 的所有核心条件（趋势、结构、价格强度、涨幅结构）在本样本中均为**损耗项**，与实盘配置的方向相悖 —— 若继续沿用现有实盘配置，应先解释这一冲突。
8. **实盘配置本身已被独立证伪（§15）**：完整复刻 `config.yaml` 后，母事件 OOS T+10 波动配对 α = **-1.07%（p=1.000）**，`gain_structure` 与 `trend` 均为减分项（Δ均值 -0.30pp / -0.35pp，子条件全负），HVT-A 级（-1.07%）显著劣于 HVT-B 级（-0.12%）。这不是"参数需要调优"，而是**条件方向与证据相反**。

**若要继续推进，必须先完成的四项工作**

1. ~~**复刻实验**：完整复刻 `solo/hvt_bull/config.yaml` 的全部条件，检验"涨幅结构约束"是加分还是减分。~~ → **已完成，见 §15**。结论：涨幅结构、趋势均为**减分项**，实盘配置的母事件本身 α 显著为负。此项已不再是"待办"，而是**新增的否决证据**。
2. **成本与容量实测**：用逐笔/分钟数据估计真实滑点，并按信号日的成交额分布测算容量上限（小市值信号占比高，容量可能极小）。
3. **尾部截断方案**：若保留策略，必须设计"止盈截断"规则并验证——但须注意，截断右尾等于截断全部 α，因此这一步极可能直接证伪策略。
4. **样本外延长**：至少补 2015-2020 数据以覆盖一轮完整牛熊，检验 2023/2026 的负 α 是周期性的还是结构性的。

### 15.6 复刻检验结论

1. **config 的母事件（HVT-A\|B）在严格无未来函数口径下 α 显著为负**：OOS T+10 α = -1.07%（同日+波动配对 p=1.000），比本文主定义 HVE（α -0.46%）更差。config 在 `vr20≥2` 之上追加的"成交额比 ≥ 2.0 + 250 日量能分位 ≥ 98"**进一步损害**绩效。
2. **`gain_structure` 是减分项**（Δ均值 -0.30pp、Δ胜率 -2.65pp，三个子条件全负）。§12 第 1 项待办已闭合，且答案是负面的。
3. **`trend` 是减分项**（Δ均值 -0.35pp，三个子条件全负），与本研究 §4.2 独立结论一致 —— 两条独立路径得到同一结论，置信度高。
4. **唯一稳定加分的是 `price_strength`，最强的是 `chip_lock`**；但 chip_lock 全链条 OOS 仅剩 n=152（IS 104），且 IS 为负，样本量不足以支撑任何结论。
5. **唯一统计显著为正的组合仍是"缩量后突破日入场"（R5b α +0.73%，p=0.047）** —— 与本研究主结论指向同一个因素：**缩量 + 突破**，而这一因素在 config 中的权重（`volume_contraction` 仅作为相似度模型 8 个权重之一，权重 12）远低于趋势与结构。
6. **即便 R5b 也未能跨过本文的否决线**：OOS 样本仅 569、IS 为负、剔除 Top5% 后 -1.11%、突破日 13.7% 涨停不可成交（剔除后仅 +0.09%）。

**综合判定：实盘配置 `config.yaml` 的入场条件集，在本样本与无未来函数口径下不成立。其"涨幅结构 + 趋势"方向与证据相反；真正有效的"缩量 + 突破"因素在配置中被稀释。**
