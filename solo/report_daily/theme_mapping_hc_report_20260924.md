零、本层相对线上系统的口径修正（重要）
────────────────────────────────────
本层在原有四状态之外新增第五状态 UNKNOWN，专门承接「无主营文本」的成员。

原因：线上 V2.4 机器层与 V2.4-HC 层的规则是「无主营文本 → WEAK」。
经实测：全库 4297 个成员对中，无主营文本 352 个（8.2%），
其中 338 个（96%）来自同一条映射通道 dc_industry_board。
把「没有文本」记成「主营与主题弱相关」是两件完全不同的事：
前者是数据缺口，后者是业务判断。本次核验把二者严格分开。

污染率定义（本层）：
污染率 = (WEAK + BAD) / KNOWN，KNOWN = N − UNKNOWN（UNKNOWN 不计入分母，也不计入分子）。

五状态定义：
CORE    核心主营 / 核心产品 / 主要收入利润来自该主题 / 产业链明确核心环节
RELATED 明确产业链关系（上游材料、核心零部件、设备、软件、配套服务），非核心主营
WEAK    弱相关（少量相关业务、参股、一次合作、新闻曾涉及、概念标签但主营不支持）
BAD     基本不属于（主营完全无关、仅因炒作进入、概念标签错误、产业链关系不存在）
UNKNOWN 无主营文本，无法判定，进入人工复核，不计入污染率

本层同时输出 MappingQuality（V1 口径，与线上 V2.4 的 MappingQuality 口径不同，两者并列展示）：
BAD  如果 BAD占比 ≥30% 或 有效占比(CORE+RELATED)/KNOWN <40%
OK   如果 BAD占比 ≤5% 且 有效占比 ≥70% 且 UNKNOWN占比 ≤30%
WARN 其余

1. 消费｜定义本身无法稳定执行（优先级最高）
   定义：「涵盖食品饮料、家用电器、商贸零售、社会服务、纺织服饰等大消费全产业链」
   行业口径：食品饮料 / 家用电器 / 商贸零售 / 社会服务 / 纺织服饰 / 轻工制造 / 农林牧渔（7 个行业）
   关键词表：消费、大消费、消费升级、品牌消费、新消费、消费龙头、必选消费、可选消费、
             日常消费、消费行业、消费主题、消费复苏、内需、扩大内需、消费刺激、促消费、
             消费券、消费市场、消费品、消费服务、消费需求、消费趋势
   问题：关键词表里没有任何一个「具体业务名词」（没有食品、白酒、家电、超市、餐饮、服装）。
        这类元词无法匹配任何一家公司的主营文本，于是 CORE 只能依赖人工名单与品牌词。
   实测：N=300，CORE 仅 10，BAD 180（60%），UNKNOWN 17，污染率 80.6%。
   矛盾点：海天味业（调味品龙头）、东鹏饮料、双汇发展、青岛啤酒、安井食品、中国中免、金龙鱼
          被判 BAD；而回盛生物（兽药）、中牧股份（兽药）、和而泰（元器件）、
          民爆光电（电气设备）、星徽股份（机械基件）被纳入池中。
   外部核验：海天味业 2025 年主营调味品，酱油 149.34 亿、蚝油 48.68 亿、调味酱 29.17 亿，
           三项合计占营业收入约八成（2025 年营收 288.73 亿）。属食品饮料消费核心。
   判定：主题定义过宽 → 建议拆分（食品饮料 / 家用电器 / 商贸零售 / 社会服务），
        或改为「具体行业 + 品牌白名单」双轨，删除全部元词关键词。

九、主题定义问题
════════════════════════════════════

一、定义过宽（行业口径把「行业」当成「主题」）
AI算力      行业口径 = 电子 / 通信 / 计算机（三个大行业）
消费电子    行业口径 = 电子（与 AI算力、半导体、机器人、军工、智能驾驶、信创 共享）
消费        行业口径 = 食品饮料 / 家用电器 / 商贸零售 / 社会服务 / 纺织服饰 / 轻工制造 / 农林牧渔（7 个）
智能驾驶    行业口径 = 汽车 / 电子
机器人      行业口径 = 机械设备 / 电力设备 / 电子
军工        行业口径 = 国防军工 / 机械设备 / 电子
信创        行业口径 = 计算机 / 电子 / 软件服务 / IT设备
电力        行业口径 = 电力 / 公用事业 / 火电 / 水电 / 核电 / 风电 / 光伏 / 电能综合服务（含设备与运营）
低空经济    行业口径 = 国防军工 / 交通运输 / 计算机
新能源车    行业口径 = 汽车 / 电力设备 / 有色金属
高端材料    行业口径 = 基础化工 / 石油化工（描述为高端化工新材料，口径却覆盖石油开采与炼化）

二、定义过窄（把核心公司排除在外）
军工        特征行业仅「航空 / 通信设备」，导致船舶总装与军工电子被判 BAD
消费        关键词全为元词（消费、大消费、消费升级、内需、促消费、消费券…），无具体业务名词，
            导致调味品、饮料、肉制品、啤酒等核心食品饮料公司被判 BAD
信创        核心在「国产替代」，而行业口径用「软件服务」，导致国产IT基础设施（中科曙光、神州数码）被判 WEAK

三、需要重新定义（结构性，不是补关键词能解决）
1. 消费：拆分或改为「行业 + 品牌白名单」双轨，删除全部元词关键词。
2. AI算力：以「环节清单」定义（AI服务器 / GPU芯片 / 光模块 / PCB / 液冷 / IDC / 算力租赁 / 数据中心），
   而不是以「电子+通信+计算机」三个行业定义；同时明确排除普通元器件、ODM、电信运营、普通软件。
3. 创新药 与 医疗器械：当前共用「医药生物」行业口径，两者无法区分，必须各自独立定义。
4. 军工：从「航空 + 通信设备」扩展为「航空 / 航天 / 船舶 / 兵器 / 军工电子 / 军工材料」环节清单。
5. 电力：明确区分「电力运营」（发电/电网/水电/核电）与「电力设备」（光伏设备/风电设备/储能设备）。
6. 智能驾驶：从「汽车」行业改为环节清单（域控制器 / 线控制动 / 线控转向 / 激光雷达 / 智能座舱 /
   车载芯片 / 高精地图），明确排除轮胎、整车、通用汽配。

四、必须同时修正的判定机制（比关键词更关键）
现有判定把「主营关键词命中」与「行业是否属于特征行业」混用，且特征行业由 CORE 成员行业分布
（占比 ≥15%）反推。这造成同一主题内的同类公司被分成 WEAK 与 BAD 两档
（如消费的白酒=WEAK、食品=BAD）。建议改为：
先定义「允许纳入的环节清单」，再按公司主营逐只判定，不使用「特征行业」作为判罚依据。

════════════════════════════════════
十、最终结论
════════════════════════════════════

当前主题系统最大的误差来源：
1. 映射来源单一且粒度太粗：85% 的成员对来自 dc_industry_board 一条通道，
   贡献了 97.3% 的 BAD。行业/板块成分股被整块倒入主题，主题边界因此消失。
   （已量化：行业通道 BAD 率 23.7%，人工名单通道 BAD 率 1.6%）
2. 判定机制混用「主营关键词」与「特征行业」，导致同一主题内同类公司被判成不同档
   （消费：白酒 WEAK / 食品 BAD；智能驾驶：轮胎 WEAK / 整车 BAD；
     军工：航空有 CORE，船舶与军工电子一律 BAD）。
   这不是「公司不属于主题」，而是「判定标准不一致」，
   直接后果是把真实核心公司（海天味业、中国船舶、伯特利、新时达）算作污染。
3. 数据缺口被错误解释：352 只无主营文本成员在线上被记为 WEAK（=弱相关），
   实际是「无法判定」。该批成员集中在军工（67）、机器人（37）、新能源车（33），
   直接压低了这三个主题的 MappingQuality。

在不修改 Heat 计算公式的前提下，优先修复：
1. 把「无主营文本」从 WEAK 中剥离为独立状态 UNKNOWN，并从污染率分母与 MappingQuality
   判定中剔除（本层已实现），同时补录北交所主营文本。
2. 把主题定义从「行业口径」改为「环节清单 + 允许/排除名单」，
   优先处理消费、AI算力、智能驾驶、军工、信创、电力六个主题。
3. 把判定依据统一为「公司主营 → 环节清单」，废除「特征行业」作为 WEAK/BAD 的判罚依据，
   消除同类公司两档并存的问题；对已识别出的误判核心公司（第六节一表）先行改判保留。

补充说明（数据质量层面）：
- 成员池污染的修复只影响「成员是否属于主题」，不影响 Heat 公式本身。
- 三个核心答案（今日 银行 / 本周 创新药 / 本月 传媒）中，
  银行映射质量 97.6%（可信度 高），创新药 30.0% 与传媒 65.0%（涨幅来自真实成员，但成员池需修复）。
- 小样本主题（脑机接口 N=6、可控核聚变 N=9、黄金 N=11、量子计算 N=6、商业航天 N=17、
  智能驾驶 N=19）即使 Heat 高，也不构成广泛主题行情的证据。

本层未修改 theme_config.json、subtheme_map.json 及任何成员池。
所有「建议删除 / 建议复核 / 建议补充」均为报告，由人工决定。
