1. 收盘价 < TRIG → BREAKOUT_FAILED：次日 NO_BUY；持仓 → EXIT_IF_CLOSE_BELOW_TRIG。
2. Volume_T+1 / Volume_breakout > 1.2 且盘中破 TRIG → 突破失败风险，NO_BUY。
3. 回踩买入成交后：止损 = INVALID；TARGET1 减半仓、TARGET2 清仓或上移保本。
4. 三种模式实际成交后，按 BUY_ZONE/CONFIRM/INVALID 三价管理，不再依赖主观判断。
