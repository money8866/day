## 数据缺口与已知限制

- 财务口径：只使用 `ann_date <= 20261027` 的报告，缺失公告日的报告一律丢弃（防未来数据泄漏）。
- 货币资金、有息负债、总负债科目未在本地缓存 → A4「短期偿债/有息负债」两项记 0 分并计入缺口，不参与打分补偿。
- 扣非净利润（`profit_dedt`）parquet 覆盖不全，缺失时该项 0 分并降低 `data_completeness`。
- 估值分位需 ≥60 个样本（近 1000 个自然日）；样本不足输出「估值待核验」。
- 形态分析用前复权价；最新一根复权价等于原始价，故支撑/失效/目标价可直接作为交易价参考。
- 摆动低点均已按「右侧 k 根 + 反弹确认窗口」确认后才计入，不存在用未来 K 线回填低点的情况。
- 模型状态：**UNPROVEN** —— 未完成严格样本外验证（T+20/T+60、最大回撤、扣费、分市场阶段、相对原始 RB 策略增量、随机池对比），不得据此宣称有效。
