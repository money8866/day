一、方法与边界
═══════════════════════════════════════════

抽样方式：每主题在 CORE / CHAIN / UNCERTAIN / EXCLUDE 四层内先按代码排序，再用固定种子随机洗牌取前 20 只，保证可复现。
盲抽字段：代码 / 名称 / 主营文本 / 行业 / 主题 / 系统分类 / 系统证据。不含股价、涨幅、热度、排名、回测收益。
判定口径：只看公司披露的主营产品、客户与产业链关系，独立重判 TRUE_CORE / TRUE_CHAIN / TRUE_UNC / TRUE_EXCL。
证据等级：A 年报中报公告；B 公司披露主营与官网；C 行业公开资料与多来源产业链资料；D 单一标签或市场传闻。仅 D 级证据不得单独支持 CORE。
特殊条款：主营文本缺失一律先判 TRUE_UNC，不得机械判 EXCLUDE；再尝试补证后升级。

方向性错误专查结果：

六、表4：规则问题
═══════════════════════════════════════════

AI算力
- RULE_CHANGE = YES：需修「环节关键词过泛」与「人工名单绕过层级」两处。
- 环节词「闪存」被映射到 HBM/存储本体；「数据中心」「云平台」「网络设备」「PCB」「背板」被宽口径命中，导致消费存储、汽车软件、物联网模组、EMS、光学膜被纳入。
- 人工名单（core_stocks）直接产出 CORE，绕过环节分层，使 PCB 等产业链环节被标为本体。
- 建议：环节词命中后增加「产品是否直连 AI 数据中心/服务器/算力」二次判定；人工名单只定义优先级，不定义层级。

智能驾驶
- RULE_CHANGE = YES：CORE 环节「车联网」口径过泛，且线控制动词误命中无关业务。
- 「车联网」把微型连接器、公交调度软件、物联网模组并入 CORE；「制动」误命中汽车制动灯。
- 建议：CORE 限定在智驾域控、智驾芯片、感知系统、决策算法、ADAS 方案商；「车联网」降为 CHAIN；线控关键词增加「线控/电子制动」等限定。

军工
- RULE_CHANGE = YES：宽口径产业链证据无证据即入链，问题最集中。
- 「液压」「发动机」「复合材料」「结构件」「元器件」「射频」「特种」「防御装备」等通用词直接产出 CHAIN，12/20 抽样 CHAIN 无任何军工业务证据。
- 另有简称命中：航天长峰因简称含「航天」进入 CHAIN。
- 建议：CHAIN 必须以公开披露的军工客户、军品目录、军工资质或军品收入为前提；通用工业词一律降级 UNCERTAIN；简称命中不得作为独立证据。

电力
- RULE_CHANGE = YES：环节行业豁免缺少经营层证据校验，且「主营含光伏」直接入链。
- 环节行业豁免使行业属电气设备/新型电力即通过，抽样 64/291 条无电力经营词。
- 「主营含电力业务表述：光伏」把光伏设备、光伏材料、光伏玻璃类公司并入电力链。
- 简称命中：亿能电力因简称含「电力」在文本缺失下被判 CHAIN。
- 建议：环节行业豁免必须叠加经营层证据（主营或年报出现发电、输配电、电网、电力工程等表述）；光伏制造设备/材料不得归入电力；文本缺失一律 UNCERTAIN。

消费
- RULE_CHANGE = YES：排除项关键词一刀切造成真实消费公司误杀。
- 「压缩机」「玻璃」「纸」「包装」「互联网」「发动机」「贸易」等排除词在主营文本中出现即整体排除，导致冰箱压缩机、家电玻璃、钢琴、按摩椅、皮具、自行车、膳食营养补充剂被剔除。
- 另有纳入侧误判：「开关」误命中家用电器（传媒）、「贸易」误命中商贸零售（金属矿贸易）、「照明」误命中 B2B 专业照明。
- 建议：排除项按「主体业务是否面向终端消费」判定而非关键词；把家电与家居的专用零部件、文教休闲消费品、健康食品补回 CHAIN/CORE 白名单。

七、表5：最终建议
═══════════════════════════════════════════

FINAL_ACTION = MINOR_RULE_FIX

理由：五主题均存在明确且可定位的系统性边界问题，但问题集中在三个弱证据通道（宽口径产业链证据命中、公司简称命中、行业环节豁免）与一个排除规则（dc_industry_board 整包一刀切排除），本体环节关键词逻辑与 CORE 主体判定基本成立，不需要推翻重建。

若不做修正直接进入 V2.4 热度计算，Heat 成员池中约四分之一为概念污染或证据不足标的，会稀释热度信号；消费则有约三分之一真实成分股缺席。

优先修正顺序：
1. 弱证据通道降级：宽口径产业链证据、公司简称命中一律先落 UNCERTAIN，需第二条独立证据才可升 CORE/CHAIN（影响最大，覆盖军工、AI算力、电力、消费）。
