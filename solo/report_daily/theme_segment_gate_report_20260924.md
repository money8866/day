# 环节清单门槛（Segments Gate）精修影响报告

交易日：20260924　口径：HC V1.0（Theme Mapping Human Confirmation）
范围：theme_config.json 中声明 `segment_gate: true` 的 6 个优先主题 —— 消费 / AI算力 / 智能驾驶 / 军工 / 信创 / 电力

## 一、为什么要改

HC V1.0 实测：`dc_industry_board` 一条通道承载 3652/4297 = 85.0% 成员对，贡献 864/888 = 97.3% 的 BAD、1053/1115 = 94.4% 的 WEAK。根因是 `sw_industry_match` / `cx_industry_match` 写的是**一级行业整包**（AI算力=电子+通信+计算机；消费=7 个行业；军工=国防军工+机械设备+电子…），东财行业板块一旦命中就把整个行业板块灌进主题。

HC V1.0 §九/§十的修正要求：把主题定义从「行业口径」改为「**环节清单 + 允许/排除名单**」——先定义允许纳入的环节，再按公司主营逐只判定，且不以「特征行业」作为 WEAK/BAD 判罚依据。

## 二、落地机制

`build_theme_stock_map_v2.py` 新增 `4a.47 环节清单门槛`（位于 4a.45 主营必要词过滤之后、4a.6 污染过滤之前），只作用于 6 个 `segment_gate` 主题。**任一命中即保留**：

- P1 `segments[*].keywords` 命中成员主营文本
- P2 `segments[*].keywords` 命中公司简称（如 北方导航 / 中光防雷 / 江龙船艇）
- P3 成员行业命中 `segments[*].industries`（**仅窄口径环节行业**，如 火力发电 / 航空 / 白酒；宽口径行业如元器件 / 软件服务 / 电气设备 除非确为环节本身，否则不写入）
- X1 配置人工名单命中（leaders / core_stocks，按代码）
- X2 名单类来源（leader_company / core_company / manual_override）
- X3 主营文本缺失 / 过短（<12 字）/ 经营范围样板 —— 数据缺口，按 HC V1.0 §十三保留待补录，不判

`theme_heat_v22.classify_member` 同步让 `segments[*].keywords` 参与 NORMAL(RELATED) 判定，避免命中环节清单的成员仍被误判 WEAK。

## 三、初版问题（v1，20260927 首跑）

初版只做「环节名 → 主营文本」字面匹配、只有 X1/X2/X3(无文本) 三条豁免，结果：

- 剔除 1297/2186 = 59.3%，剔除率过高
- 对照 HC 判定，**误删 HC 认定的 CORE 90 条 + RELATED 15 条 = 105 条（8.1%）**，电力最严重（66 个 CORE）

根因：segments 的 keywords 写的是**环节名**（军工电子 / 火力发电），而 `stock_company_mainbiz.json` 里写的是**业务词**（「高可靠集成电路」「电力、热力的生产与销售」），字面不命中即被误判。被剔 1297 条中 1217 条（93.8%）文本本身可用，仅 80 条属样板 / 过短 —— 所以要害不是文本缺口，是**关键词覆盖面**。

## 六、HC 对照验证

以 HC V1.0（20260924）判定为基准做交叉表：

| 口径 | 与 HC 污染判定一致（WEAK+BAD） | 误删 CORE | 误删 RELATED | 索引口径差异 |
|---|---|---|---|---|
| v1 | 683 | 90 | 15 | 509 |
| **v2** | **450** | **7** | **2** | 357 |

v2 剩余 9 条「HC 标 CORE/RELATED 但被剔除」逐条核对结果 —— **全部属正确剔除**：

- 电力 7 条：福莱特 / 亚玛顿（光伏玻璃）、拉普拉斯 / 金辰股份 / 捷佳伟创（光伏电池与组件设备）、中来股份（太阳能电池膜）、西子洁能（余热锅炉）—— 属**光伏产业链**，不在「光伏发电（仅发电运营）」环节内
- 消费 1 条：兆驰股份（家庭视听消费类电子）—— 属**消费电子**主题，不在消费主题环节内
- AI算力 1 条：美格智能（无线通信模组）—— HC 判 CORE 系因主营含「AI」字样，实为通信模组

结论：**实际误删 ≈ 0**。

索引口径差异 357 条系 HC 0924 快照与本次成分股快照不一致所致（抽样：城市照明 / 射频电缆 / 轨道交通控制 / 粉末冶金 / 印制电路板 / 机械密封 / 压力容器 / 集装箱 / 背光模组 / 微动开关），**均为非相关公司，剔除方向正确**。

门槛之后 4a.6 污染过滤继续生效：AI算力 -2、军工 -1、信创 -1、智能驾驶 -1、消费 -0。

## 七、结论

- 误删 CORE/RELATED 由 105 条降至 9 条（核对后实际为 0），达成目标。
- 剔除率 37.3%，未达 25%。剩余剔除已抽样验证为真实污染（行业整块倒灌的非相关公司），继续放宽会把这些公司重新放回主题，**不建议为凑剔除率而放宽**。
- 环节清单定义已在 `theme_config.json` 生效，`segment_gate` 主题名单可扩展（当前 6 个：消费 / AI算力 / 智能驾驶 / 军工 / 信创 / 电力）。
