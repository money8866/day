零、任务边界（先声明）
════════════════════════════════

本模块只做一件事：判断「每个主题的成份股是否真的属于该主题」。
Heat 公式、Reliability、Percentile、P50/P75、排名参数：全部未改动，一行未改。
本报告不重算 Heat，不据「哪个主题该强」调成员，不输出任何综合评分。
Heat 排名仍完全由原 V2.3 / V2.4 算法决定。

数据口径（关键）：
- 原池 = theme_pregate_pool_20260924.csv（4a.45 后 / 4a.47 前，门槛前），5824 条。
  该口径与规格引用的 AI算力 316 / 智能驾驶 104 / 军工 464 / 电力 376 / 消费 669 完全一致。
- 对照 = theme_stock_map_v2_20260924.csv（当前生产映射），4297 条。
- HC 旧判定 = 4297 条（用于对照原分类）。
- 环节门槛剔除 816 条、污染过滤剔除 422 条。

四级定义（本报告唯一口径）：
CORE 明确属于主题 / CHAIN 主题产业链关键环节 / UNCERTAIN 证据不足待复核 / EXCLUDE 明确不属于。
正式 Heat 成员 = CORE + CHAIN。UNCERTAIN 默认不进正式 Heat，保留在审计库。

Q1　哪些主题的 Mapping 明显存在污染？
电力：环节行业豁免 291 条，其中 64 条仅凭行业标签、无电力经营证据；审计判 EXCLUDE 且仍在生产映射 47 条。

另有 24 个主题的生产映射仍残留审计判 EXCLUDE 成员共 1351 条（机器人 253 / 新能源车 261 / 创新药 132 / 化工 99 / 高端材料 95 …），
属「旧映射未按 V3 口径清理」，构成潜在污染。

Q2　哪些主题存在过度剔除？
明示证据：被环节门槛剔除但审计判 CORE/CHAIN 共 47 条（军工 19 / AI算力 14 / 电力 9 / 智能驾驶 5）。
保留率口径提示的高风险主题：机器人 12.2% / 低空经济 19.5% / 可控核聚变 23.7% / 高端材料 24.3% / 创新药 25.5% /
智能驾驶 26.9% / 新能源车 27.9% / AI算力 30.4% / 军工 32.5% / 消费电子 32.9%。
其中 AI算力、智能驾驶的剔除依据经核查为「行业整包倒入」而非「文本缺关键词」，属**剔除偏严但方向正确**；
机器人、低空经济、高端材料、可控核聚变四个主题的剔除量级最需人工复核。

Q3　哪些主题存在「环节豁免过宽」？
电力（唯一明确命中）：291 条环节行业豁免中 64 条无经营层证据，47 条审计判 EXCLUDE。
次要风险：建筑装饰（87.0% 保留，CHAIN 81/100，且未启用环节门槛，与已启用主题口径不一致）。

NOT_READY

1) 电力主题存在实质性、仍在生产映射中生效的成员错配（47 条 EXCLUDE、64 条无经营证据豁免），会直接扭曲电力 Heat。
