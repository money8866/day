## 一、核心逻辑

V2.1 对 V1 的核心修正：**股息是安全垫，不是目标**。
要买的是「便宜且能持续赚钱、且市场开始愿意给钱」的公司，而不是单纯的股息率排序。

- 下行保护(DP)：股息率≥3% 提供缓冲 + 估值安全边际 + 现金流与资产质量
- 成长质量(GQ)：增长强度 + 加速 + ROE + 毛利结构 + 盈利含金量
- 上行参与(UP)：趋势结构 + 相对强度 + 位置 + 量能 + 行业强度

**总分 = 0.45×DP + 0.35×GQ + 0.20×UP**（权重随市场状态自适应）

股息率分区间处理：≥3% 为门槛；3~4% 正常；4~6% 优秀；**>6% 进入核查区**，须排查股价崩塌 / 净利下滑 / 扣非下滑 / 分红支付率过高 / 周期顶部，命中即降级。

高股息陷阱（CYCLE_TRAP）判定：净利转负或扣非大幅下滑单信号即定性；扣非为负、分红趋势衰减、明显回撤、分红支付率过高四项信号累计 ≥2 项；股息率 >6% 时单信号即警戒；周期行业股息率 ≥5% 且景气/回报走弱。

## 十、数据来源与使用说明

- 股息率持续性：daily_basic_cache 逐日 dv_ttm 回看 3 年
- 市场状态：index_daily_cache 上证指数（缺失回退 TDX .day）
- 行业/上市日：stock_basic.csv

使用说明与风险提示：
- 三支柱权重随市场状态自适应：牛市抬升 UP（趋势参与），弱市抬升 DP（下行保护）。
- VALUE_BUY 与 TREND_BUY 是两条独立通道，同一只股票可能同时满足（BOTH）。
- 股息率 >6% 不等于更好，往往是股价下跌或一次性分红所致，报告已单列核查区。
- CYCLE_TRAP 为避雷名单，即使总分高也不参与（周期顶部的高股息最危险）。
- 本报告为基本面+趋势的横截面筛选结果，不含仓位与止损规则，建仓前请另行制定交易计划。
- 数据均来自本地缓存，使用前请确认缓存已更新至最新交易日。
