# 月度ETF龙头股筛选系统使用说明

## 📋 配置文件位置

配置文件位于: `D:\mystock\config\.env`

已包含以下配置：
- TUSHARE_TOKEN
- DEEPSEEK_API_KEY
- WECHAT_SCKEY

## 🚀 运行方法

### 1. 基础版（月度龙头筛选）

```bash
cd d:\mystock\solo
python monthly_etf_dragon.py
```

### 2. 增强版（推荐，包含AI基本面分析）

```bash
cd d:\mystock\solo
python monthly_etf_dragon_enhanced.py
```

## 📊 筛选条件

- **最小周期**: 月线
- **市值要求**: 总市值 > 100亿
- **双创优先**: 科创板+20%加分，创业板+10%加分
- **趋势筛选**: 月线MACD金叉 + 均线多头排列
- **涨幅限制**: 本月涨幅 < 30%
- **成交量**: 月成交量 > 近期均量的1.5倍
- **风险检测**: ST、减持、增发、财务风险

## 🎯 龙头评分体系

综合得分 = 涨幅得分×25% + 成交量得分×25% + 趋势得分×20% + 基本面得分×15% + 弹性得分×15%

### 调整筛选参数

在代码中修改以下参数：

```python
# 市值阈值（万元）
if market_cap < 1000000:  # 100亿
    continue

# 涨幅阈值（%）
if return_month > 30:
    continue
```

## ⚠️ 注意事项

1. **API配置**: 确保 `D:\mystock\config\.env` 中填写了有效的Tushare Token
2. **API限制**: Tushare有调用频率限制，代码中已添加延时
3. **缓存机制**: 数据会缓存到 `cache_backbone_tushare` 目录
4. **AI分析**: DeepSeek API为可选配置，不填则使用默认分析
5. **数据延迟**: 月度数据可能有1-2天延迟
