## 二、“确定性走强日”典型形态

综合4只强势股数据，一个高置信度的“确定性走强日”拥有以下完整的日线技术画像：

**1. 价格形态 (K线 & 位置)**
*   **形态**：收出一根**实体大于3.5%的中阳或大阳线**。阳线实体覆盖前1-3日的弱势调整K线。
*   **位置**：发生在二次探底成功或回踩关键均线（如MA20）后，价格重新站上MA5和MA10。这通常不是趋势的绝对最低点，而是“分歧转一致”的突破点。

**2. 均线系统**
*   **短期均线**：MA5上穿MA10，完成金叉或拒绝死叉的空中加油形态。
*   **中期均线**：MA20明确向上。股价收盘价一举站上MA5和MA10，并距离MA20不远，形成短期进攻形态。
*   **长期均线**：MA60已经走平并开始向上，提供坚实的下方支撑。

**3. MACD状态**
*   **柱状图**：MACD柱由绿翻红，或绿柱连续2日缩短后，当天出现**放大的第一根红柱**。
*   **DIF/DEA**：在零轴上方（或下方很近的位置），DIF线拐头向上，接近或已经完成金叉。这是“确定性走强”最关键的动能确认。

**4. 量能特征**
*   **成交量**：成交量必须显著放大。是前一日成交量的**1.8倍以上**，且**超过MA5和MA10均量线**。
*   **换手率**：换手率健康放大，表明筹码充分交换，新的买入力量强劲。例如，688525当天换手率可达7%以上，002709可达6%以上。

**5. RSI/KDJ位置**
*   **RSI**：6日RSI从40-50区域快速拉升至**55-70的强势区**，形成陡峭的攻击角度。
*   **KDJ**：KDJ在50附近完成金叉，K、D值发散向上，显示短期上攻动能充沛。

**3. “确定性走强日”盘中买入触发条件（触发当日）**：
*   **时间**：开盘后1小时至收盘前1小时。
*   **触发信号（满足3条即可行动）**：
    1.  **价格突破**：股价实时涨幅 > 3%，且分时图强势突破MA5和MA10。

## 五、确定性走强评分公式（总分 0~100）

本公式用于对一只股票在任意交易日进行打分，分数越高，当日成为“确定性走强日”的概率越大。  
**包含六大模块**：均线排列（20分）、MACD 状态（20分）、RSI 位置（15分）、量能与换手（20分）、BOLL 位置（10分）、价格偏离度（15分）。

### 1. 均线排列分（A，满分 20 分）
评估短期、中期、长期均线的多头排列程度。

| 条件 | 得分 | 备注 |
| :--- | :--- | :--- |
| `MA5 > MA10 > MA20 > MA60` 全部满足 | 20 | 完美多头排列 |
| `MA5 > MA10 > MA20`，但 `MA20 ≤ MA60` | 12 | 短期强势，中期尚未完全转多 |
| `MA5 > MA10`，其余不满足 | 6 | 仅有短期攻击信号 |
| 其余情况 | 0 | 均线混乱或空头 |

**注意**：若当日 `MA5` 刚刚上穿 `MA10`（今日金叉日），可额外附加 2 分，但总分不超过 20。

---

### 2. MACD 状态分（B，满分 20 分）
衡量趋势动能以及金叉的共振程度。

使用参数：`DIF`、`DEA`、`MACD柱`（均为日线）。取最新值。

| 条件 | 得分 |
| :--- | :--- |
| `DIF > 0` 且 `DIF > DEA` 且 `MACD柱 > 0` 且 `MACD柱 > 前一日` | 20 |
| `DIF > 0`，`DIF > DEA`，但 `MACD柱` 缩短（红柱缩短） | 15 |
| `DIF > 0`，`DIF ≤ DEA`（死叉状态），但 DIF 已经开始向上拐头 | 10 |
| `DIF > 0`，死叉且仍在向下 | 5 |
| `DIF ≤ 0` | 0 |

**附加规则**：  
- 若 `DIF` 和 `DEA` 均位于零轴上方（即 `DIF>0` 且 `DEA>0`），基础分额外 +2，上限仍为 20。  
- 若今日为 `DIF` 上穿 `DEA` 的金叉日，且 `DIF > 0`，则直接给 20 分（最强共振）。

---

### 3. RSI 位置分（C，满分 15 分）
使用 6 日 RSI。既要反映强度的提升，也要避免极端超买后的回调风险。

| RSI6 值范围 | 得分 | 说明 |
| :--- | :--- | :--- |
| `50 ≤ RSI6 < 65` | 15 | 最佳攻击区，动能充足且未过热 |
| `65 ≤ RSI6 ≤ 75` | 12 | 强势，但有一定回调压力 |
| `45 ≤ RSI6 < 50` | 8 | 刚从调整中恢复，可信度略低 |
| `75 < RSI6 ≤ 85` | 5 | 极度超买，追高风险大 |
| `RSI6 < 45` 或 `RSI6 > 85` | 0 | 弱势区或严重超买区 |

**附加条件**（可不叠加）：  
- 若过去 5 个交易日 RSI6 的最低值 ≥ 38，且今日 RSI6 > 55，说明回调确认强势，得分再加 1 分（不能超 15 分上限）。

---

### 4. 量能与换手分（D，满分 20 分）
结合量比（当日成交量/5日均量）与换手率健康度。

**量比子项（0~12 分）**：

| 量比范围 | 得分 |
| :--- | :--- |
| `1.5 ≤ 量比 < 2.5` | 12 |
| `1.2 ≤ 量比 < 1.5` | 8 |
| `2.5 ≤ 量比 ≤ 4.0` | 8 （放量过大，需观察） |
| `0.8 < 量比 < 1.2` | 4 |
| `量比 ≤ 0.8` 或 `量比 > 4.0` | 0 |

**换手率子项（0~8 分）**：

| 换手率范围 | 得分 |
| :--- | :--- |
| `3% ≤ 换手率 ≤ 10%` | 8 |
| `2% ≤ 换手率 < 3%` 或 `10% < 换手率 ≤ 15%` | 4 |
| 其余 | 0 |

**量能总分 = 量比得分 + 换手率得分（最高 20）。**  
*依据统计数据，强势股换手率中枢 5.53%，范围多在 1.7%~10.3%，3%~10% 框定最优区间；量比 >1.5 占比仅 20%，因此作为高分阈值。*

---

### 5. BOLL 位置分（E，满分 10 分）
使用布林带（20,2）判断趋势延续性和爆发点。

| 条件 | 得分 |
| :--- | :--- |
| 收盘价 ≥ BOLL上轨，且带宽（上轨-下轨）> 20日均带宽1.1倍（张口加速） | 10 |
| 收盘价位于上轨与中轨之间，且股价站上中轨（强势区） | 7 |
| 收盘价位于中轨与下轨之间，但股价今日站上中轨（突破中轨） | 5 |
| 收盘价在中轨与下轨之间 | 2 |
| 收盘价跌破下轨 | 0 |

---

### 6. 价格位置分（F，满分 15 分）
考察收盘价与短期及中期均线的偏离度是否处于“不过远、不过近”的强攻位。

**MA5 偏离度得分（0~8 分）**：  
`偏离5 = 收盘价/MA5 - 1`，以百分比计。

| 偏离5 范围 | 得分 |
| :-- | :-- |
| `+1.5% ~ +5.5%` | 8 |
| `+0.5% ~ +1.5%` 或 `+5.5% ~ +8.0%` | 5 |
| `-0.5% ~ +0.5%` | 3 |
| 其余 | 0 |

**MA20 偏离度得分（0~7 分）**：  
`偏离20 = 收盘价/MA20 - 1`

| 偏离20 范围 | 得分 |
| :-- | :-- |
| `+5% ~ +15%` | 7 |
| `+2% ~ +5%` 或 `+15% ~ +20%` | 4 |
| `0% ~ +2%` | 2 |
| 负值或 >20% | 0 |

（依据统计数据：MA5偏离均值+4.93%、中位数+3.62%；MA20偏离均值+13.79%、中位数+7.79%。设定居中区间为高分，避免乖离过大的风险。）

### 总分汇总
```
确定性走强评分 = A + B + C + D + E + F
```
**建议使用阈值**：
