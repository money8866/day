# 实时监控自动任务设置说明

## 已创建的文件

| 文件 | 说明 |
|------|------|
| `start_emotion_monitor.bat` | 大盘情绪监控启动脚本 |
| `start_ma_monitor.bat` | 均线监控启动脚本 |
| `setup_tasks.bat` | 自动设置任务脚本（需管理员权限） |
| `自动任务设置说明.md` | 本文档 |

## 设置方法

### 方法1：手动设置（推荐，最可靠）

#### 步骤：

1. 打开任务计划程序
   - 按 `Win + R` 键
   - 输入 `taskschd.msc`
   - 回车

2. 创建大盘情绪监控任务
   - 右侧点击"创建基本任务"
   - 名称输入：`实时大盘情绪监控`
   - 点击"下一步"
   - 触发器选择："每天"
   - 开始时间：`9:25`
   - 勾选"仅在每周以下日期运行"，选择周一至周五
   - 操作选择："启动程序"
   - 程序或脚本：`d:\mystock\solo\start_emotion_monitor.bat`
   - 起始于（可选）：`d:\mystock\solo`
   - 点击"完成"

3. 创建均线监控任务
   - 重复步骤2
   - 名称输入：`实时均线监控`
   - 程序或脚本：`d:\mystock\solo\start_ma_monitor.bat`

4. 优化任务设置（可选）
   - 在任务计划程序中找到任务，双击打开
   - 切换到"条件"选项卡
   - 取消"仅当计算机空闲时启动此任务"
   - 切换到"设置"选项卡
   - 勾选"如果任务失败，按以下频率重新启动"
   - 点击"确定"

### 方法2：命令行设置（需要管理员权限）

右键点击 `setup_tasks.bat`，选择"以管理员身份运行"

## 验证任务

设置完成后：

1. 在任务计划程序中找到刚创建的任务
2. 右键点击，选择"运行"
3. 查看是否正常启动程序

## 任务特性

- **运行时间**：每个工作日（周一至周五）9:25
- **自动启动**：开盘前5分钟自动运行
- **监控内容**：
  - 实时大盘情绪监控（每5分钟）
  - 实时均线监控（每1分钟）

## 手动启动测试

可以直接双击以下文件测试：
- `start_emotion_monitor.bat` - 测试大盘情绪监控
- `start_ma_monitor.bat` - 测试均线监控

## 停止任务

1. 在任务计划程序中找到任务
2. 右键点击，选择"结束"
3. 或直接关闭运行的窗口

## 删除任务

1. 打开任务计划程序
2. 找到任务，右键选择"删除"
3. 确认删除

## 故障排除

- **任务未运行**：检查计算机是否在9:25处于开机状态
- **权限问题**：确保以管理员权限创建任务
- **路径错误**：确认bat文件路径正确
