## 九、口径与声明

- **无未来函数**：行情仅用 `trade_date <= 扫描日`；财报仅用 `ann_date <= 扫描日`；事件仅用 `ann_date <= 扫描日` 且落在回看窗口内。
- **均量不污染**：`BreakoutVR = VOL_today / MA20_VOL(不含今日)`；`DryUpRatio = MA20_VOL / MA120_VOL`，两者均严格排除当日成交量。
- **结构字段口径**：突破类（EDB / EDB_STRONG / EDB_WATCH / EDB_PULLBACK / EDB_REBREAKOUT）的 Base / 缩量 / 压缩 / 平台 / 突破质量取**突破日快照**；现价 / MA20 / MA60 / MA120 / 距250日高 取**当日值**。
- **评分边界**：VR > 5 不再加分并标记 CLIMAX_VOL；涨停不自动提分；EDB_SCORE 不直接等于 BUY。
