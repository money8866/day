## 0. 最终结论（前置）
────────────────────────────────────────────
**结论：UNPROVEN**

第三层「尾盘再启动」依赖分钟级真实行情（禁止用日线伪造尾盘信号）。本机通达信 5 分钟线（.lc5）实测仅覆盖约 60 个交易日（20260224 ~ 20260522），无法满足统计有效的样本量，更无法做有意义的样本外验证。按策略规范：分钟级历史数据不足时必须输出 UNPROVEN。因此本策略当前既不能被判定为 PASS，也不能被判定为 FAIL，结论为 UNPROVEN（证据不足，待更长分钟数据后复测）。

作为参考（不构成尾盘策略验证）：日线层 L1+L2（前期强势 + 缩量回踩，T+1 开盘入场）在 2025-01~2026-09 三段长历史中样本外产生 1779 个信号、平均净收益 -64.2bp。该结果仅用于说明「缩量回踩」这一日线结构本身是否具有统计意义，不能替代 EOD-RB 的尾盘择时效果。

## 7. 运行说明
────────────────────────────────────────────
1) 依赖：pandas / numpy / mootdx；复用 bts 数据层（bts.data）与本地通达信数据。
2) 一键全量回测 + 报告：python -X utf8 -m eod_rb.run
3) 每日信号（当日分钟数据到位后）：
     from eod_rb.daily import generate_daily_signals, build_table
     sigs, regime = generate_daily_signals('20260522', EOD_RB_CONFIG)
     print(build_table(sigs))
4) 消融实验：from eod_rb.ablation import run_ablation
5) 参数稳定性：from eod_rb.stability import run_stability
6) 全部阈值集中在 eod_rb/config.py 的 EOD_RB_CONFIG，禁止散落硬编码。
7) 成本：单边 15bp + 分钟内滑点 5bp；净收益已扣佣金/印花税/过户费/滑点。
8) 每份 results.json 记录数据日期、信号生成时间、参数版本、成交假设与退出基准。
