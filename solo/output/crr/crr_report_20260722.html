四、数据缺口、代理口径与未实现模块

估值模块（模块四）口径说明

  • pe/pb 便宜度分位：daily_basic_cache 近 5 年日频序列，当前值在正值样本中的『历史更贵占比』
  • 历史中枢取正值 PE/PB 的中位数（抗极端值），当前隐含 TTM 盈利 = total_mv / pe_ttm（与 PE_TTM 自洽）
  • 绝对上限封顶：PE_TTM > 60 或 PB > 12.0 时该项记 0 分（判定明确，非缺失），计入归一分母
  • forecast_downgrade：forecast_vip p_change_min/max 中值（单侧缺失取单侧）作为『盈利预期变化』代理
  • drop_vs_downgrade：跌幅取模块二 ret20（复权累乘口径，负值取反），盈利下修幅度 = max(0, -预告同比变动)
  • 伪低估值判据：PE 便宜度分位高 + 预告盈利下修

估值模块已知缺口

  • EV/EBITDA 本地无字段（无 EV、无息负债）→ ev_ebitda_pct 恒 UNKNOWN，按可用权重归一，不记 0
  • 本地无逐日盈利一致预期，也无历史预告版本序列（load_forecast 已按 (ts_code,end_date) 取最新公告去重），无法计算真正的『盈利预期修正幅度』→ forecast_downgrade 以预告同比变动作代理，已在 proxies 披露
  • forecast_vip 本地仅覆盖 20260630 中报预告，其余报告期无预告 → forecast_downgrade / drop_vs_downgrade 多为 UNKNOWN
  • PE/PB 历史样本不足 250 个交易日（上市时间短）→ 便宜度分位判 UNKNOWN，不以短样本近似
  • PE_TTM <= 0（亏损）→ PE 便宜度分位与合理市值缺口均判 UNKNOWN；PB 分位仍可用
  • fair_value_gap 与 pe_ttm_pct 同源于 PE 历史分布，存在口径重叠，已在 proxies 披露
  • 合理市值用『历史 PE 中枢 × 当前 TTM 盈利』近似，未做 DCF/可比公司/盈利正常化，属简化口径
  • 若盈利预期下修，历史 PE 中枢会高估合理市值 —— 该风险由 v_pseudo_value 标记提示，是否降级由 engine 依据 DECISION 决定，本模块不否决
  • 模块四仅占 25 分；其余 45 分/抛压衰竭/资金回流/模块五六见 PENDING_MODULES，不参与本模块评分

基本面模块（模块三）口径说明

  • 金融股识别：申万 l1 优先；l1 为 UNKNOWN 时用公司名关键词(银行/证券/保险)兜底
  • SLI l1_name 实测仅『银行』『非银金融』，保险/证券/多元金融并入非银金融，覆盖度照实标注
  • deducted_profit_growth 回退链：sli.dt_netprofit_yoy → parquet profit_dedt 同比 → parquet n_income_attr_p 同比(净利代理)
  • ocf_match 回退：sli.ocf_to_profit 缺失时用 parquet cashflow/income 同报告期 经营现金流/|归母净利|
  • gross_margin_trend：sli (grossprofit_margin-gm_prev) → fina 序列相邻报告期毛利差(月份差<=4)
  • recent_3q：fina 序列最近 3 期 netprofit_yoy 均值，不足 3 期回退 or_yoy
  • forecast_change：forecast_vip p_change_min/max 中值（单侧缺失取单侧）
  • parquet 现金流为年内累计口径：连续 N 季 OCF 为负须同年内差分得单季且相邻月差<=4，Q1 本身即单季

基本面模块已知缺口

  • interest_debt(有息负债) 本地无字段 → 恒 UNKNOWN，按可用权重归一，不记 0
  • parquet fina_indicator_.gross_margin 为毛利额(绝对值)非比率 → 毛利率改用 fina.grossprofit_margin / sli
  • parquet balance.goodwill 大量为 NULL → 不可当 0，判 UNKNOWN
  • 无 ann_date 的 parquet 家族(fina_indicator_q_/yoy_)由 data 层直接判 UNKNOWN 不读取
  • forecast_vip 本地仅覆盖 20260630 中报预告，其余报告期无预告 → forecast_change/forecast_type UNKNOWN
  • 金融股豁免 debt_to_assets 打分与否决（不计入归一分母）
  • VETO 无数据不触发，缺口写入 q_veto_unknown / q_unknown_fields
  • 模块三仅占 30 分；模块四 25 分 + 其余 45 分/抛压衰竭/资金回流/模块五六见 PENDING_MODULES，不参与本模块评分
