## 1. Executive Summary

本轮回答两个问题，答案**一正一负**：

    P1  Alpha 是否存在 Regime Dependence ？        → 是（4/4 Alpha 显著）
    P2  Regime 是否可以被 OOS 识别 ？              → 否（WEAK_DETECTOR）

具体地：

1. **P1 通过。** 在观测窗口内，四个 CORE Alpha 的 30bp 后单笔平均收益在不同 Regime
   标签下差异达 **1.31% ~ 3.31%**，而同样本量下的置换零分布 95 分位仅
   **0.18% ~ 1.65%**（B=1000，p<0.001）。**同一个 Alpha 在不同市场状态下确实表现不同**，
   这不是噪声。

2. **但 P1 是事后（ex-post）事实，不是可交易信息。** P1 的置换检验把 IS+VALID+OOS
   整段窗口合并使用，属于"看完全样本后才知道哪些格子好"，本身不构成 OOS 证据。

3. **P2 未通过，且是硬失败。** 三条独立证据：

   - **检测器本身是噪声级的。** 5 态标签平均持续 **2.41 个交易日**，
     持续时间 ≤2 日的状态占 **74.1%**；标签在 t+20 的存活率只有 **27.4%**
     （5 态下随机基线约 20-25%）。SPEC §11 判据直接触发 `WEAK`。
   - **Regime 对未来的信息量不存在。** 用 **IS 窗口（2022-2023）** 学出的
     Regime→Alpha 最优映射，原样搬到 **OOS（2025-01~2026-09）** 后，
     被选中交易的 30bp 后均值 = **-0.12%**，而全部交易的均值 = **+0.04%**，
     差值 **-0.16%**，置换检验 **p=0.743**——即 **74.3% 的随机抽 Alpha 都比它好**。
   - **历史格子排名不迁移。** 20 个 (Alpha × Regime) 格子的 IS 与 OOS 平均收益
     秩相关仅 **Spearman 0.182**（Pearson 0.291）。多个格子直接符号翻转
     （如 Alpha A 的 R2：IS -3.03% → OOS +0.48%）。

4. **一个更基础的问题：四个 CORE Alpha 在 OOS 扣 30bp 后基本不赚钱。**
   OOS 单笔净收益：A **-0.31%**、B **-0.12%**、C **-0.10%**、D **+0.88%**。

**本轮结论：H-AOS-01 在当前样本、成本假设与 OOS 设计下不被支持（FAIL）。**
按任务书 §32 的研究优先级，P2 未通过，**不得进入 P3（Alpha Health）、P4（Router）、
P6（Null / Walk-Forward）、P7（ML Router）**。

## 7. Failure Analysis（主动寻找失败原因）

按要求，本节只找"为什么可能失效"，不报告成功。

### 7.1 为什么 Q1 显著但 Q3 无信息？

这是本轮最重要的观察。合理解释有四个，且都可检验：

1. **IS 窗口太短且不具代表性。** IS 只有 484 个交易日，且 R1（强趋势）仅占 6.6%。
   用一段没有强趋势的样本去学"强趋势时该用哪个 Alpha"，本质上无法学到。
   OOS 里 R1+R2 占 45.1%——**训练集与测试集的状态构成严重不同**。
2. **检测器把"状态"做成了"日噪声"。** 平均 2.4 天的持续期意味着
   "当前 Regime"这个变量本身就没有跨日的稳定性；用它做路由等于每天重新掷骰子。
3. **Alpha 之间的差异本来就小且不稳定。** 全部格子的均值都挤在
   ±3% 的窄带里，而单笔收益标准差远大于此。选错的代价高，选对的收益低。
4. **P1 的显著性部分来自样本量而非效应量。** C 有 232,507 笔交易，
   极小的均值差在这么大的 N 下也会显著。**统计显著 ≠ 经济可用**。

### 7.2 这个失败是"实现有 bug"还是"假设不成立"？

自查过的泄漏防线（SPEC §20 全部通过）：

    [√] 阈值只作用于 IS 区间（regime_thresholds 只读 2022-01-01~2023-12-31）
    [√] rolling 统计只用 <= t（_vr_excl 分母不含 t；_roll_max_prev 用 shift(1)）
    [√] Regime 标签在 t 只用 <= t 信息（features 无 shift(-n)）
    [√] 前向收益只用于结果度量，不进入任何选择规则
    [√] 买入日为 t 或 t+1，无同日未来价（C 用 open[T+1]，D 用 open[entry]）
    [√] Universe 按当日 PIT 判定
    [√] 成本逐笔扣减

反方向的证据（说明不是实现问题）：

    - R4 是唯一次日收益显著为负的状态，R5 波动最高且次日为正 —— 分类语义正确
    - 矩阵结构（R4 对所有 Alpha 都最差）符合经济直觉
    - IS/VALID/OOS 三段的 whipsaw 都在 0.72-0.77，问题不限于某段
    - 置换检验的零分布构造正确（保留两边边际）

**结论：这是假设层面的失败，不是实现层面的 bug。**

### 7.3 为什么这是一个有价值的结果

任务书 §34 的要求：如果答案是 NO，应分析"为什么 Alpha 失效不可预测"。

本轮的答案比"不可预测"更精确：

> **失效是可以被事后观测的（P1 证明了 Regime 与表现相关），
> 但无法被转化为前瞻性选择规则（P2 证明了这一点），
> 因为承载该信息的 Regime 变量本身不具跨期稳定性，
> 而四个 Alpha 的 OOS 扣除成本后经济边际几乎为零——**
> **即使路由完全正确，可分配的超额收益也不足以覆盖成本。**

这解释了为什么"Regime 路由"在概念上合理却在本样本中无法实现：
**问题不在路由器，在于没有值得路由的 Alpha，以及没有稳定的 Regime。**
