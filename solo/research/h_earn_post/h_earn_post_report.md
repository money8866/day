# 十五、§51 必须回答的 12 个问题

**1. 中报后的基本面改善是否仍然存在？**
存在，但微弱且不稳健。FSC/SIG_RESID 全样本 T+20 mean_IC = +0.0344（t = 1.89），未达 1.96；逐年看 2021/2022/2023 连续三年 ≤ 0，2025 才回到 +0.0536。

**2. 中报后 20–30 个交易日，价格是否已经充分反映基本面？**
**未被充分反映（毛口径），但不可交易。** 证据：E20 的 `SIG_RESID` Top-Bottom 毛价差 T+20 = +0.0081，反事实匹配后 High-FSC 组仍领先 +0.0085（t 3.42）。但组合层 30bp 后年化超额 −5.26%，净价差 −0.0039。即"错配存在，但全部小于交易成本"。

**3. High Fundamental Surprise + Low/Moderate Price Reaction 是否存在 Alpha？**
**形式上为正、经济上不存在。** `SIG_QUADA`（§13 A 象限）E20/T+20 mean_IC = +0.0387（高于所有候选）、AUC = 0.5110；但 **Momentum 中性后翻转为 −0.0302**（§45 `MOMENTUM_PROXY`），AUC 低于 0.52，组合超额 −6.66%。象限 A 捕获的是低动量暴露，不是基本面错配。

**4. Alpha 最早从什么时候出现？**
**在 Entry 之前就已出现，Entry 当天即已存在。** Entry 锚点 T+1 的 mean_IC 已有 +0.0169（E20），T+3 达 +0.0375；而从 D0 锚点看，T+1 ~ T+20 的 IC 在 ±0.008 之间摆动（噪音）。**不存在"Entry 之后才启动"的结构**。

**5. T+5、T+10、T+20、T+60 哪个阶段最明显？**
E20：+0.0165 / +0.0226 / **+0.0344** / −0.0191 → **T+20 最大，T+60 转负**。E25/E30 在 T+20 与 T+60 均为负。§25 判定为 **TYPE B（早期反应后衰减）**。T+60 转负与"二次定价在中报后逐步被发现并持续"的假设**直接矛盾**。

**6. Alpha 是否独立于 Momentum？**
**是，但无增量价值。** 与 CTRL_MOM 横截面相关仅 +0.0159；Momentum 中性后 IC 反而略升至 +0.0372。**真正的失败在于绝对水平**：候选信号 IC +0.0344 **远低于** B1_MOM +0.0817 → §44 `NO_INCREMENTAL_ALPHA`。独立 ≠ 有用。

**7. Alpha 是否独立于 Value？**
是。与 CTRL_VAL 相关 −0.0647；MOM+VAL 中性后 IC = +0.0460（未衰减）。

**8. 行业中性后是否仍存在？**
**是。** 申万一级中性（`FULL_SW`）后 IC = +0.0301（原 +0.0344），近似无衰减。但注意：申万一级缺失率 40.97%，行业中性化的样本覆盖面有限；且行业中性**不能**修复逐年方向翻转。

**9. Random Stock 是否可以复制？**
**E20 不能复制**：N1 z = 3.17 ≥ 2.0（delta = +0.0353）。**E25/E30 可以复制**：z = 0.10 / −1.31 → 区间后段完全等效于随机选股。

**10. Random Date 是否可以复制？**
**E20 不能复制**：N2（同股票 Entry 平移 ±40 交易日）z = 3.45 ≥ 2.0（delta = +0.0278）→ 排除纯时间效应。**E25/E30 可以复制**：z = −0.67 / −0.81。

**11. 成本后能否形成经济意义？**
**不能。** E20 组合毛年化超额 −0.31%（**毛即负**），30bp 后 −5.26%；成本网格 0/10/20/30/50bp 在 E20 六种选股口径下**全部为负**；全表 30 个 (Entry × 选股) 格中仅 3 个在 **0bp** 时为正（最大 +1.08%），10bp 起全部转负 → `COST_FRAGILE`。

**12. 最终能否转化成 Portfolio vs Benchmark 的真实超额？**
**不能。** `LONG_EW` 预注册组合 **72 / 72** 个 (Entry × 选股 × Horizon) 在 30bp 后超额 ≤ 0（IR 全部为负，−0.09 ~ −1.22）；即使按 §11.4 的"持仓日部署口径"，毛超额为正（+12.5% ~ +29.0%），但其平均暴露仅 **14%–42%**，现金拖累（58%–86%）加上固定成本后仍为负 → `COHORT_ALPHA_DOES_NOT_TRANSLATE_INTO_PORTFOLIO_ALPHA`。
