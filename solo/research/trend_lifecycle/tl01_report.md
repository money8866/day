§50 必须回答的核心问题（Q1 – Q15）
══════════════════════════════════════════════════════════════════════════════

**Q1 趋势是否存在稳定生命周期？**

部分存在（YES-WEAK）。11 状态的转移矩阵结构清晰、可重复（一步自持 S0 90.890% / S7 87.890% / S3 29.610%），Model B 聚类（K=6）一阶对角留存更稳定（76.000%–88.900%）。但 Model A 的多数状态（S3/S4/S5/S8）平均持续时间 ≈ 1 日、隔日翻转，"生命周期"体现在**转换结构**而非**状态持续**。

**Q2 生命周期状态是否具有不同的未来收益分布？**

YES。T+20 均值最高 S0_非趋势（1.86%）与最低 S5_高位拥挤（-0.74%），跨度约 2.60%；S4/S5 的 MFE20/MAE20 同时最大（S5 MFE20 17.97% / MAE20 -14.00%），赔率反而最差（S5 RR20 1.28）。

**Q3 状态转换是否比静态 Trend Strength 更有预测力？**

YES（本样本内）。SIG_TS IC20 = -0.0573 vs SIG_TRANS IC20 = 0.0697；SIG_TV -0.0210 / SIG_TA -0.0083 亦为负或近零。

**Q4 Trend Acceleration 是否提供增量信息？**

NO。SIG_TA 全样本 IC20 = -0.0083（ICIR -0.0795），SIG_TV = -0.0210。加速本身无独立信息；且加速类转换 S3→S4（-0.81%）、S4→S5（-0.81%）、S8→S4（-0.73%）的 T+20 均值为负。

**Q5 Trend Age 是否具有预测力？**

YES-WEAK。T+20 均值随 Age 递减（Age 1-5 1.15% → Age 41-60 -0.98%，Age 60+ -0.05%），三个年龄分界的 young-old 差为 0.85%/1.00%/1.40%；SIG_AGE IC20 = 0.0479（ICIR 0.3619），但 OOS IC 仅 0.0223，量级偏小。

**Q6 正常回撤与趋势终结能否事前区分？**

NO。S7 的三个出口极度不平衡：留 S7 87.889% / 转 S8 2.312% / 转 S9 0.0184%（452 例）/ 转 S10 0.00016%（4 例），事前分类在统计上不可行。SIG_REACC IC20 = -0.0143 亦无预测力。

**Q7 回撤后的再启动是否存在稳定 Alpha？**

NO。S7→S8 的 T+20 均值仅 0.18%（中位 -1.75%，胜率 43.9%），且不具显著性；独立构造的 SIG_REACC 无预测力。

**Q8 Trend Lifecycle 是否只是 Momentum 的重新包装？**

NO（符号相反），但增量有限。全部 Baseline IC20 为负（B1_MOM20 -0.0729、B2_MOM60 -0.0714、B3_MA20 -0.0636、B4_MA60 -0.0840、B5_RS20 -0.0729、B6_POS60 -0.0548）而 SIG_TRANS 为正；然而加入 Momentum/Size/Value/Vol/Industry 控制后，TRAIN IC 转负（-0.0048）、OOS 仅剩 0.0133。结论：**不是包装，但独立增量不足以形成可交易 alpha**。

**Q9 是否存在跨年份稳定性？**

YES。SIG_TRANS T+20 IC 在 9 个自然年全部为正（最低 Y2020 0.0366）；下钻到季频，33 个季度亦全部为正（最低 0.0019 出现在 2021Q2），无单年 / 单季翻转。

**Q10 是否存在跨 Regime 稳定性？**

YES。T+20 IC：BEAR 0.0872 (t=5.12) / NORMAL 0.0369 (t=2.01) / BULL 0.0725 (t=7.05)，三档同号，无频繁反转；NORMAL 最弱。

**Q11 是否存在参数稳定区域？**

YES。两组 3×3 网格的 OOS IC 范围分别为 [0.0691, 0.0724]（ma×trend）与 [0.0703, 0.0766]（rs×dd），同号比例 1.00，粗糙度 0.0134/0.0225，无孤立高点 → SMOOTH。

**Q12 是否能够通过 OOS？**

IC 层 PASS（T+20 0.0704, ICIR 0.7342, t=3.56），判别力层 FAIL（AUC 0.4547 < 0.52）。

**Q13 是否能够通过 Null Model？**

YES。N3 随机状态置换在 5 个 horizon 上 |z| = 2.29–2.78，p = 0.0010，BH-FDR 全部拒绝。

**Q14 扣除 30bp 成本后是否仍有经济意义？**

NO。30bp 后四分期超额分别为 -2.84% / -0.62% / -13.46% / -7.86%。

**Q15 最终是否值得进入策略研究？**

NO（本研究 V1 不授权）。结构性信号值得**继续研究**（属于 CONDITIONAL），但当前形态不足以作为交易信号进入 TL-02；须先解决「顶端判别力（AUC<0.5）」与「右尾依赖」两个前置问题。
