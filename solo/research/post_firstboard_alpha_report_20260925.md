# 首板后可交易量价 Alpha · 自动科研报告 V2.0

研究日期：2026-09-25
研究对象：A 股首板（T0 有效涨停）之后，T+1/T+2 已可完整观测、且可实际成交的量价 / 换手 / 价格结构信息，对 T+3 / T+5 收益的预测能力。

## 0. 数据口径与限制声明（先声明，后结论）

本报告所有结论都在下列口径约束下成立，任一约束不满足时结论不成立。

1. **数据起点不是 2018，而是 2021-04-06**。项目现有 Tushare cache 的复权面板从 2021-01-04 开始，首板事件最早 2021-04-06。任务书默认的 TRAIN 2018–2023 实际只能取到 2021-04 ~ 2023-12。样本量由原设计约 6.5 万事件降为 33,401，**TRAIN 期样本偏少是本研究的结构性约束**。
2. **换手 / 市值类特征在 TRAIN 期覆盖不全**。`daily_basic_cache`（换手率、总市值）自 2023 年起才完整，`F_TOHEAT` 五分位在 TRAIN 期每层仅约 745 只。涉及换手的结论以 TRAIN 为弱证据、以 VALID/OOS 为强证据。
3. **无可靠盘中数据 → 不模拟盘中 Entry**。按任务书 §7 强制条款，E1/E2 全部采用「**收盘信号 → 次日开盘成交**」，E3（盘中信号）**未执行**。
4. **首板定义可复现**：直接取项目已有 `limit_list`（交易所口径涨停），不使用「涨幅 ≥ 9.8%」的近似；按板块真实涨跌幅（主板 10% / 创业板·科创板 20% / 北交所 30% / ST 5%）归一，改用**首板前 20 个交易日内是否出现过涨停**（`prev_lim20`）判定「首」，而非用涨幅阈值。已剔除 ST / *ST / 退市整理 / 上市不足 60 个交易日。
5. **所有统计先在「月内截面」排名 / 分层，再跨月聚合**。这是本研究的核心方法约束：若直接在全样本做 IC 或分层，相邻交易日的首板事件会抱团（同一波行情内同涨同跌），产生「时点效应伪 Alpha」。月内截面口径下，任何 Alpha 必须是「同一批首板里挑出来的那几只更强」，而不是「某几个月行情好」。
6. **特征族的选取存在轻度的全样本曝光**。§9 特征空间由任务书给定（无自由度）；但「把 `dma20_2/dma60_2/ma10slope_2/…` 归为 OVEREXT 复合因子」这一步，参考了 §12 全样本扫描的 IC 排序（含 OOS）。**方向由 TRAIN 决定，复合权重为等权（无权重搜索），阈值取固定远端分位（无网格搜索）**，但仍应在读结论时打一个折。

## 1. Executive Summary

**判定：CONDITIONAL**

一句话原因：首板后 T+1/T+2 可观测信息的**方向是单一的、且被反复验证的——「越冷静的开局越好，越亢奋的开局越差」**。全部 92 个特征中，高 |IC| 者无一例外为负向；由此构造的候选 **C3 = 非超买（OVEREXT 低 40%）+ 相对强（RS 高 40%）** 通过了可交易性、无未来信息、OOS 有效、匹配反事实成立、参数扰动平滑五项硬检验（真实可交易 T+3 开盘入场后 OOS T+5 中位 **+0.83%**、胜率 **52.4%**、PF **1.32**）；但它**未能通过第 ⑪ 项「赢家/输家事前可区分性」**（组内 Winner vs Loser 最大标准化差异仅 0.19~0.29，LOW_DISCRIMINATION），且时间稳定性弱（月度正比例仅 43.8%，BULL 环境为负，2026 盈利集中于 Q3）。因此按任务书 §38，**不允许 PASS**；同时它不落入 §32 的任一 FAIL 条件（OOS 未失败、无锚点反转、无 Selection Effect、参数不敏感、样本充足），故为 **CONDITIONAL**。

**C3 的性质必须写清楚**：它是一个**组合层的规避性过滤 / 权重倾斜**（在首板池里剔除「超买 + 相对弱」的那一半），**不是**一个可以逐只下注的个股 BUY 信号。

### 4.2 非线性读法（不要假定「越大越好」）

1. **量能与换手是单调下行的，不是 U 型。** 交易者直觉里常见的「温和放量好、极端放量差」的 U 型，在本样本中并不存在——**从 Q1 到 Q5 单调恶化，Q5 最差**。这一点对「放量 = 强势」的直觉是直接否定的。
2. **波动类（amp2 / rng2 / rvol20_2 / hl_ratio_2）呈 INV_U**：最高波动段最差，但次高档（Q4）也不优于 Q1。
3. **收盘位置（cp2）呈弱 INV_U**，而「离 T0 收盘的距离」（distC0_2）与「两日平均收盘位置」（cp_mean12）是**严格单调下行**。差异说明：**不是「收盘高不好」，而是「已经走得离首板收盘越远越不好」**。这正是过度反应的口径。
4. **相对强弱自身是弱 INV_U 且整体为负**（五个分位全负）。它是一个**条件变量而非独立 Alpha**，理由见 §5 与 §33-Q6。

### 6.3 锚点审计的三条结论

1. **C3 存在锚点衰减（约 -80%），但未反转。** T0 锚点 +3.016% → 真实可交易 +0.616%（OOS +1.084%）。按 §29「Event 很好 / Real 很差 → REJECT」，此处**不构成 REJECT**，因为真实入场仍显著为正。但必须记录：**若有人在任何材料里引用「首板后买 C3 有 +3%」是错的，真实可交易只有 +0.62%（扣成本 +0.36%）**。

3. **同一份数据里，「锚点漂移陷阱」被完整捕获了三个实例**：`Z1_OVEREXT 高 20%`（A1 +7.633% → A4 -3.122%）、`Z2_VOLHEAT 高 20%`（+3.947 → -2.454）、`C8_cp2 高 20%`（+3.785 → -1.668，且 A2 为 -2.090，非单调）。**如果不做 §29，这三个都会被误当作「首板后强势形态」，而它们在真实可交易口径下是负收益。** 这与本项目历史上「三花 / 缩量突破 / 分歧→缩量→再启动」的失败原因是同一种错误。

### 10.2 最终判定

**STATUS = CONDITIONAL**

**Evidence（支持）**
- 方向结构统一且跨期稳健：92 个特征中 81 个 TRAIN/VALID 同号且 OOS 未反号，全部高 |IC| 者为负 → 「过度反应反转」是真实结构，不是抽样噪声。

- 对入场口径不敏感（E1 +0.766% / E2 +0.361%，A2–A5 平缓），说明不是锚点依赖。
- 全部 8 类失败率均低于基准，不是靠尾部风险换收益。
- 非行业 Beta（月×行业中性后超额仍 +0.90pp）、非单一市值段（Large/Mid/Small 皆正）、非单一 Regime（3/4 为正）。

**Reason（不足以 PASS）**
- **⑪ LOW_DISCRIMINATION**：组合层有 Alpha，个股层无法事前分辨赢家 —— 只能做成**组合层过滤**，不能做成个股 BUY 信号（§31）。
- **时间稳定性弱**：月度正比例 43.8%，BULL 环境为负（-1.667% vs 基准 -1.172%，**跑输基准 0.50pp**），OOS 盈利集中于 2026Q3。
- **经济意义薄**：扣 0.255% 成本后 OOS T+5 中位 +0.829%，0.655% 成本下 ALL 中位转负。
- **构造敏感性**：等价的构造方案在 OOS 上从 -0.110% 到 +0.829% 不等；且**两个分量单独使用都无效**（仅非超买 ALL -0.42%、仅相对强 ALL -1.89%），收益完全来自交集 → 存在「观察后选择」的残余风险。

**Risk（使用风险）**
1. 它是**低胜率正期望结构**（月度 43.8% 为正），短期连续亏损期会很长，需按组合层使用。
2. **OOS 只有 187 只、且依赖 2026Q3**，样本外结论不够厚，需继续跟踪而非立即实盘放大。
3. **中小盘暴露偏高**（流动性不足占比 39.3% > 基准 33.5%），必须叠加成交额下限，否则实际滑点会超过 0.3% 假设。
4. **BULL 环境下为负**，需显式加入 Regime 条件（见策略 JSON 的 `regime_filter`）。

## 附：最终报告必须回答的 Q1–Q12（§33）

**Q1 首板后哪些变量最有预测能力？**
「距离 / 趋势延展」类最强：`dma60_2`(-0.141)、`ma10slope_2`(-0.138)、`dma20_2`(-0.138)、`ma20slope_2`(-0.132)、`distlo20_2`(-0.126)、`ma5_over_ma20`(-0.120)；其次是换手与波动类（`to2` -0.095、`to_vr2` -0.087、`amp2/rng2` -0.079）。全部为负向。

**Q2 预测 T+3 和 T+5 的变量是否一致？**
**高度一致。** IC3 与 IC5 的排序几乎重合（前 12 名同一批），且 |IC5| 系统性大于 |IC3|（如 dma60_2：-0.110 → -0.141）。说明这是**持续性的修复过程**，不是短期噪声；T+5 是比 T+3 更合适的持有窗口（T+10 仍继续增强）。

**Q3 量能究竟是正向、负向还是非线性？**
**单调负向，不是 U 型。** `vr2` 五分位 -0.661 → -1.989 单调恶化；`F_VOLHEAT` 复合 -0.336 → -2.455。**没有任何一个分位是正的**，即「首板后放量」在本样本中不存在「适度即好」的区间。

**Q4 换手是否具有独立 Alpha？**
**不具备强独立 Alpha。** `to2` / `to_vr2` / `to_cum012` 单变量确有 -0.09 级别的 IC，但在 §16 增量阶梯中，加入「非换手过热」条件后中位数反而从 -0.205% 变差到 -0.252%（Δ -0.047pp）——即**在已控制超买之后，换手不提供增量**。结论：换手与量能高度共线，只宜作条件变量，不宜单独成信号。

**Q5 价格位置是否具有独立 Alpha？**
**有方向性信息，但不足以独立成信号。** `distC0_2`(-0.081)、`distL0_2`(-0.097)、`cp_mean12`(-0.073) 均为负；但最直接的「收盘位置」候选 **C8（cp2 高 20%）在真实可交易口径下翻转为 -1.668%**（§29 ANCHOR_DRIFT），说明单纯「收盘高/低」是陷阱。价格位置只能作为 OVEREXT 复合的成员（`distC0_2`），不能单独使用。

**Q6 相对强弱是否提供增量信息？**
**提供的是「条件增量」，不是无条件增量。** 单独筛「RS 高 40%」ALL T+5 中位 **-1.89%**（比基准 -1.03% 更差）；但叠加在「OVEREXT 低 40%」之上，OOS 从 -0.760%（仅非超买）提升到 **+0.829%**（+1.59pp）。**即 RS 只有在「开局不亢奋」的前提下才有正向价值。**

**Q7 哪些变量只是市值 / 行业 / 市场 Beta？**
- **行业 Beta：可以排除。** 月×行业中性化后 C3 超额仍为 +0.899pp（OOS +0.937pp）；行业集中度低（最大行业占比 8.9%，10 个 N≥30 行业中 9 个为正）。
- **市值 Beta：基本可排除，但有小盘倾斜。** C3 在 Large/Mid/Small 三段 ALL 均为正（+0.026 / +0.467 / +0.694）；但 C3 的「成交额 < 2 亿」占比 39.3% 高于基准的 33.5%，**存在轻度小盘暴露**。
- **市场 Beta：部分存在。** C3 在 BEAR 环境收益最高（+2.625%），而基准 A 在 BEAR 也是正的（+1.313%）——这部分是市场 Beta；但 C3 相对基准在 NORMAL/RANGE/BEAR 分别领先 +1.75 / +1.91 / +1.31pp，**说明存在独立成分**。
- **另外需注意**：`t0_ret5prev`（-0.078）、`t0_distma20`（-0.093）等「首板前已涨多少」类变量，其预测力有一部分是**「前期涨幅 → 反转」的既有 Beta**，不是首板之后的新增信息。

**Q8 是否存在稳定交互项？**
**只有一个具有经济意义且稳定的交互：超买 × 相对强（条件型）。** 表现为「非超买」单独只把中位抬到 -0.174%，只有再叠加「相对强」才进入正区间（ALL +0.361% / OOS +0.829%）。此外「超买 × 量能过热」是同向加强型交互（A3×B3 -2.979%），只能用于剔除，不能用于选股。

**Q9 真实可交易 Entry 后是否仍然有效？**
**是，但强度大幅衰减。** T0 收盘锚点 +3.016% → 真实 T+3 开盘 +0.616%（扣成本 +0.361%），衰减约 80%；OOS 为 +2.963% → +1.084%（扣成本 +0.829%）。同时 C3 对入场时点不敏感（A3/A4/A5 = +1.021 / +0.616 / +0.491；E1 口径 +0.766%），**未触发 §29 的 REJECT 条件**。

**Q10 OOS 是否成立？**
**成立，但脆弱。** OOS（2026-01-01 ~ 2026-09-24，N=187）T+5 扣成本中位 +0.829%、胜率 52.4%、PF 1.32、匹配反事实 +1.827pp。**但内部严重不均**：2026Q1 -2.508%（N=34）、Q2 -0.318%（N=77）、Q3 +1.684%（N=76）——若 OOS 截至 6 月底结论为负。

**Q11 Alpha 是否能够事前区分赢家和输家？**
**不能。** C1/C2/C3 组内 Winner vs Loser 的最大标准化差异仅 0.19~0.29，且最强区分变量就是筛选条件自身的构造成分。**标记 LOW_DISCRIMINATION** —— 即使历史平均收益存在，个股层面的事前识别能力不足。

**Q12 最终是否值得进入短线交易系统？**
**只值得以「组合层规避性过滤 / 权重倾斜」的形式进入，不值得作为个股 BUY 信号。** 具体：在首板池中剔除「超买（OVEREXT ≥ 60 分位）或相对弱（RS ≤ 60 分位）」的标的，对剩余标的降低仓位上限，并在 BULL 环境下停用。落地前必须叠加成交额下限（≥ 2 亿元）并将滑点假设设为 ≥ 0.3% 做压力测试。
