### 3.3 反事实结论（§20 必须回答）

**Alpha 来自哪一步？答案是：不来自任何一步，正向部分来自锚点错配。**

1. **A→B：无增量。** B 覆盖 99.81% 的 A，ΔT+5 = −1.278（事件链）；差异仅源于把进场时点从 T0 推迟到回撤日，是**时点代价，不是信息增量**。
2. **B→C（加缩量）：条件化 ΔT+5 = −2.233，事件链 +1.461。** 两个口径符号相反 → 条件化的「缩量有害」与事件链的「缩量有益」都不能作为结论；可交易口径的 +1.461 主要来自把进场从回撤日推迟到缩量窗口结束日的时点效应（B 的 T5 中位 −2.050 → C 的 −0.589，绝对值仍为负）。
3. **C→D（加结构未破）：ΔT+5 +1.293 / +0.334。** 方向一致、幅度明显收窄，且 C 与 D 在事件链口径下 T+5 均为负（−0.589 / −0.255），是「亏得少」而非「赚得到」。
4. **D→E（加再启动）：ΔT+5 +1.935 / −0.374。** **两口径符号相反** → 再启动这一步是否为正向贡献，结论不可靠。
5. **E→F（加结构过滤）：ΔT+5 +0.584 / +0.046。** 事件链下几乎为零 → 结构未破条件在已选中的再启动样本上**没有增量信息**。
6. **F→G（加量能确认）：ΔT+5 −1.528 / −0.458。** **两口径一致为负** → 唯一结论明确的一步是：**再加量能确认只会变差**（与 §5 的 L5 单调恶化曲线一致）。

**因此：「完整形态有效」这一说法在本研究中被明确否决。** 可交易口径下 F 组 T+5 中位 −0.583、超额 +0.511、win 46.5、pf 0.991；G 组超额 −0.101、pf 0.827 —— **扣除成本后无正向期望**。

能，已量化并验证：`dd = cl / runmax − 1`（盘中口径 `ddl = lo / runmax − 1`）首个 ≤ −th 的交易日。但结论是**它几乎不是一个条件**：D1b（≤−2%）覆盖 99.81% 的首板（31,197/31,255），D1a（≤−1%）覆盖 99.20%。**「第一次分歧」在宽松阈值下是恒真坐标；在严格阈值下（≤−8%，覆盖 84%）则与未来收益单调负相关。**

**Q2 分歧后的「卖压衰减」是否具有预测价值？**
**没有预测价值，且方向与研究假设相反。** 缩量（V1 低、V2 低、V3 低、V4 长）单调对应负收益，量能扩张（V2/V3 高）单调对应正收益（§5.1–5.4）；缩量阈值 28 组组合全为负（§5.5）。

**Q3 什么叫「结构未破」？**
已枚举 S1–S8 并让实验判断：S5/S6/S7（站上 MA5/MA10/MA20）与 S8_dd15 为负；S2（不破首板实体中位，N=899，T+5 +0.789）与 S8_dd5（N=734，T+5 +1.371）为正但 N 偏小；S3（不破首板收盘，N=154，T+5 +9.741）样本过小且含义等价于「几乎没跌」，判为**采样偏差而非有效定义**。加入完整链条后（D→F）结构未破条件**无增量信息**（§3.3 第 5 点）。

**Q4 什么叫「重新转强」？**
候选 R1–R7 已枚举。R1/R2/R3/R6/R7 微弱为正（T+5 +0.02 ~ +0.21，T+10 +2.3 ~ +3.5），R4/R5（均线类）为负（T+5 −3.05 / −3.15）。**结论：突破价格类定义优于均线类定义；但"重新转强"的正向不足以弥补前置步骤的负向。**

**Q5 分歧→缩量→再启动是否存在 T+3/T+5 Alpha？**
**不存在。** 可交易口径 F 组 T+5 −0.583（超额 +0.511、win 46.5、pf 0.991），OOS −1.557；G 组三期全负。

**Q6 哪些变量贡献最大？**
条件化口径下：**量能扩张比率（V3 > V2 > V6 > V4 > V1）> 分歧深度（D1/D4）> 收盘强弱（D2/D2b）**。但**这些「贡献」在换成可交易口径后全部坍缩到 ±1pp 以内并大量翻转符号**（§6.3）→ 它们的解释力来自「入场前已实现的漂移」，不是可获取的 Alpha。

**Q7 是否存在非线性阈值？**
不存在可利用的非线性拐点。所有曲线（V1/V2/V3/V4/V6、VR 曲线、分歧深度梯度）**均为单调**。§31 稳健中心法找到的同号区间共 6 处，其中 5 处（C/S/VT/E + L1 的 14 项区间）**同号但为负**，仅 R1~R3 同号为正且幅度微弱。

**Q8 Alpha 是否独立于首板质量 / 市值 / Regime / HVT / 突破策略？**

- **首板质量**：不独立但也无增量 —— 首板质量只作用于 B 组（近似 A 组），进入 C/G 组后消失（§8）。
- **市值**：不独立。B 组 Large −0.520 / Mid −1.115 / Small −1.587，**大市值优于小市值**（与「小市值弹性更好」的直觉相反），但 C/G 组各档全负。
- **Regime**：**强依赖，且是唯一残留正号**（bear）。但该正号属于 Regime 而非结构（§7 论证）。
- **HVT**：**近似独立**（月度相关 0.135、重合 7.43%），但双方在该区间均为负，正交不产生价值。
- **突破策略**：**本次未完成同口径对照**（属未完成项，见附录-C 局限）。

**Q9 训练集发现的规律能否在 OOS 保持？**
**不能。** 训练集选中链路（D1b → V1≤1.0 → S8_dd10 → R2 → VT1.2 → E5）的每一环在 TRAIN 上给出的「稳健区间」在 OOS 上要么一致为负（C/S/VT/E），要么符号翻转（E_V2、E_M1），要么仅在 VALID 独年为正（F/G）。

**Q10 最终是否值得形成一个新的短线策略因子？**
**不值得。REJECT。**

## 附录 D：不可交易口径（条件化）与可交易口径（事件链）的差异说明
════════════════════════════════════════

本次研究识别出一个**方法论陷阱**，并据此推翻了核心假设，值得记录：

- **条件化口径（锚点 T0）**：所有分组都从 T0 收盘进场，用于**纯测条件的信息含量**。它回答「知道这个条件后，从 T0 持有到 T+N 的收益是多少」。此口径允许使用 T0 之后才可见的信息，因此**不可交易**。
- **事件链口径（各自锚点）**：从条件被满足（指标可见）之日的收盘进场。**可交易**。

**当条件本身与「T0 之后的上涨」相关时（如「回撤 2% 但收盘位置仍 ≥0.6」），条件化口径会把这段已实现的上涨计入收益，从而制造虚假 Alpha。** 本研究中：

- 条件化 D2b：T+5 +3.258（超额 +4.031，pf 4.19）
- 同候选可交易化（E_Q1）：T+5 −3.069（超额 −1.287，pf 0.603）

**差值约 6.3pp/5 日，全部来自入场时点的错配。** 因此本报告的所有核心结论均以**可交易口径（事件链）**为准，条件化口径仅用于回答 §20 的「Alpha 来自哪一步」。
