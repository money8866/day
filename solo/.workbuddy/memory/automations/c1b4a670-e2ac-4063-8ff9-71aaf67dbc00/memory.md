## 运维要点
- 脚本自带交易日判断、重试与失败降级告警；**单次失败不要手工重跑**，避免同一交易日重复推送。
- 推送失败且报 token 相关错误时，调用 `mcp__wechat-clawbot-push__resync_credentials` 自愈后重试一次。
- 校验推送正文用 `--dry-run --no-run --date YYYYMMDD`（只打印，不推送、不重跑分析）。
