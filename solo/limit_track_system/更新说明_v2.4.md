## 🎯 本次更新核心内容

### 1. **板块热度识别功能**

#### 功能说明
系统现在可以**实时识别各板块的热度**，包括：
- 板块内涨停数量统计
- 热点持续天数追踪
- 热度趋势判断（冷/温/热）

#### 评估指标
| 指标 | 说明 | 评分贡献 |
|------|------|----------|
| 板块涨停总数 | 过去10天内板块涨停次数 | 最高30分 |
| 热点天数 | 3只以上涨停的天数 | 最高25分 |
| 热度趋势 | 近期是否升温 | 最高15分 |

#### 热度等级
- 🔥 **热（hot）**：近期涨停数明显增加
- 📈 **温（warming）**：保持稳定
- ❄️ **冷（cold）**：涨停稀少

#### 示例展示
```
工业富联 (601138.SH)
   二波概率: 100%
   行业: 通信设备
   板块热度: ❄️ 0只涨停（cold）
```

### 2. **洗盘/出货精细判断逻辑**

#### 功能说明
系统可以**精细化判断股票处于洗盘还是出货阶段**，基于6大技术指标：

#### 评估指标
| 指标 | 洗盘信号 | 出货信号 |
|------|---------|---------|
| **成交量** | 极度缩量（量比<0.6） | 放量异常（量比>1.5） |
| **价格位置** | 高位区间（>80%） | 低位区间（<30%） |
| **均线支撑** | 多头支撑（MA5>MA10>MA20） | 空头压制（MA10>价格） |
| **振幅** | 收窄（<2%）蓄势 | 扩大（>5%）分歧 |
| **MACD** | 多头（DIF>0） | 空头（DIF<0） |
| **回调幅度** | 健康（-10%~5%） | 过深（<-15%）或过大（>15%） |

#### 判断结果
- 🟢 **洗盘（wash）**：洗盘概率 > 出货概率 + 20%
- 🔴 **出货（shipment）**：出货概率 > 洗盘概率 + 20%
- 🟡 **不确定（uncertain）**：两者接近

#### 示例展示
```
工业富联 (601138.SH)
   二波概率: 100%
   行业: 通信设备
   信号: 🟡 洗盘60%/出货40%
```

### 3. **二波概率计算增强**

#### 新增评分维度

| 评分项 | 满分 | 说明 |
|--------|------|------|
| 回调幅度 | 25 | 首板后回调是否健康 |
| 均线多头 | 20 | 价格均线是否多头 |
| 高位震荡 | 15 | 价格是否高位震荡 |
| 缩量特征 | 20 | 是否缩量调整 |
| 突破前期 | 10 | 是否突破前期高点 |
| 近期涨停 | 10 | 涨停频率 |
| 市场情绪 | 5 | 市场整体氛围 |
| **板块热度** | **70** | **板块是否热点** |
| **洗盘信号** | **25/-15** | **洗盘加分/出货减分** |

**总分 = 所有评分项之和（封顶100%）**

## ⚠️ 重要提示

### 1. 板块热度重要性
- 即使个股符合所有特征，如果板块不在热点，也可能没有表现
- **热点板块 > 冷门板块**
- 建议优先关注 🔥 和 📈 的板块

### 2. 洗盘/出货信号重要性
- 🟢 **洗盘信号**：暗示主力在清洗浮筹，后市看涨
- 🔴 **出货信号**：暗示主力可能在派发，风险较大
- 🟡 **信号不明**：需结合其他指标和基本面判断

### 3. 仓位控制
- **热点板块 + 洗盘信号**：可适当加重仓
- **冷门板块 + 出货信号**：建议空仓观望

### 4. 风险提示
- 所有分析仅供参考，不构成投资建议
- 市场有风险，投资需谨慎
- 建议设置止损位（-5%~7%）
