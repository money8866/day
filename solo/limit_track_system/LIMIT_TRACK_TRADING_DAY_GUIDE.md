# 涨停跟踪系统 - 交易日智能判断快速指南

## 📅 智能日期选择逻辑

### 核心规则

1. **自动识别非交易日**
   - 周六、周日自动切换到上一个交易日
   - 法定节假日自动切换到上一个交易日

2. **16点前判断**
   - 交易日 16:00 前：使用上一个交易日（数据未更新）
   - 交易日 16:00 后：使用当天数据

3. **手动指定日期**
   - 指定非交易日 → 自动切换到上一个交易日
   - 指定交易日 → 使用指定日期

## 🚀 日常使用

### 不指定日期（自动判断）
```bash
# 今天（系统自动判断）
python limit_track_review.py

# 输出示例（周六）：
# ⚠️ 20260530 为非交易日，已自动切换到上一个交易日: 20260529
```

### 指定日期
```bash
# 分析特定日期
python limit_track_review.py 20260529

# 分析上周五
python limit_track_review.py 20260523
```

### 强制刷新
```bash
# 强制使用指定日期，忽略智能判断
python limit_track_review.py 20260530 --force
```

### 判断优先级

1. 检查周末（周六周日）
2. 查询Tushare节假日数据
3. 检查是否为当天且时间 < 16:00
4. 返回合适的交易日

## ⚠️ 注意事项

1. **节假日数据**：依赖Tushare的节假日数据
2. **时间基准**：基于服务器本地时间
3. **强制模式**：`--force` 参数可绕过智能判断
4. **缓存影响**：强制刷新不影响日期智能判断

## 💡 使用建议

- **日常使用**：直接运行，不指定日期，让系统自动判断
- **查看历史**：指定具体日期，系统会自动处理非交易日
- **调试模式**：使用 `--force` 强制测试特定日期
- **缓存管理**：定期使用 `--clear-cache` 清理缓存
