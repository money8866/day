# 更新说明 v2.6

## 更新日期
2026-05-30

## 新增功能

### 1. 基本信息缓存
- 新增 `BASIC_CACHE_DIR` 用于存储股票基本信息缓存
- 实现 `get_stock_basic_info()` 函数，带缓存获取股票基本信息（含市值）

### 2. 市值过滤
- 实现 `filter_market_cap()` 函数
- 过滤市值低于40亿的小票（可配置）
- 无法获取市值的股票暂时保留

### 3. 5日线乖离过滤
- 实现 `calculate_ma5_deviation()` 函数
- 计算5日线乖离率和距涨停日收盘价距离
- **注意：当前乖离过滤暂时禁用，待数据验证后再启用**

### 4. 工业富联企稳特征分析
实现 `analyze_stabilization_signal()` 函数，学习工业富联特征：

**工业富联特征（5月22日-27日）：**
- 5月22日：低位带下影小阳线（企稳信号）
- 5月26日、27日：连续小阳线（企稳信号）

**分析特征包括：**
- 低位下影小阳线（25分）
- 连续小阳线（25分）
- 缩量整理（20分）
- 回调幅度（10-20%区间最佳，20分）
- 均线多头（10分）

### 5. 调整企稳信号专区
- 实现 `select_top_stabilization_candidates()` 函数
- 报告新增"🔔 调整企稳信号"专区
- **最多显示3只**，按企稳分数排序

### 6. 报告优化
- 新增企稳信号专区
- 保留原有重点推荐和潜在候选
- 显示更多分析特征

## 效率优化

### 1. 缓存机制完善
- 涨停数据缓存：`LIMIT_CACHE_DIR`
- 日线数据缓存：`DAILY_CACHE_DIR`
- 基本信息缓存：`BASIC_CACHE_DIR`

### 2. DeepSeek调用优化
- 只有企稳分数>=30或二波概率>=60才调用AI
- 节省API调用次数

## 过滤条件

| 条件 | 说明 |
|------|------|
| ST股票 | 过滤 |
| 市值<40亿 | 过滤 |
| 跌破涨停日开盘价>5% | 过滤 |

## 最新过滤逻辑

**调整过程中跌破涨停日开盘价超过5%的股票将被过滤掉**

这是新增的过滤条件，确保只保留在涨停价附近震荡整理的股票，避免选择已经破位的标的。
