### 2. **新增核心特征：高位震荡缩量筛选**
#### 筛选条件
- **价格相对位置**：股价在涨停价的 85% ~ 115% 区间震荡
- **缩量特征**：当前成交量相比涨停时缩量 20% 以上（量比 < 0.8）

#### 评分机制
- **高位震荡得分**：符合条件得 15 分，部分符合得 10 分，否则得 5 分
- **缩量特征得分**：
  - 量比 < 0.6：20 分（缩量 40% 以上）
  - 量比 < 0.8：15 分（缩量 20% 以上）
  - 量比 < 1.0：10 分（小幅缩量）
  - 其他：5 分

---

### 3. **强化 AI 分析：板块热点轮动**
#### DeepSeek 提示词优化
新增分析维度：
1. **基本面匹配度**（股票基本面是否符合游资风格）
2. **板块热点轮动**（股票所属行业是否为当前热点）
3. **高位震荡缩量**（是否符合洗盘特征）
4. **游资操盘特征**（是否具备游资偏好特征）
5. **二波启动信号**（是否有明显启动迹象）
6. **风险提示**（主要风险点）

## 🚀 使用方法

### 日常使用
```bash
# 分析（自动判断是否为交易日）
python limit_track_review.py
```

### 回溯历史数据
```bash
# 回溯前 20 天数据
python full_backtrack.py

# 自定义回溯天数
python limit_track_review.py --backtrack --days 30
```

### 查询历史数据
```bash
# 查询所有数据
python limit_track_review.py --query

# 查询日期范围 + 最小概率
python limit_track_review.py --query --start-date 20260501 --end-date 20260529 --min-prob 60

# 导出 CSV
python limit_track_review.py --query --export history.csv
```

## ⚠️ 重要提示

1. **高位震荡缩量可能是洗盘，也可能是出货**
   - 洗盘特征：缩量但价格在关键支撑位
   - 出货特征：缩量但价格跌破重要均线

2. **板块热点轮动很重要**
   - 即使个股符合特征，但板块不在热点也难有表现
   - 关注市场主线，避免参与冷门板块

3. **严格控制仓位**
   - 游资炒作风险较大
   - 建议单只股票仓位 < 10%

4. **历史数据仅作参考**
   - 市场在变化，不能完全依赖历史模式
   - 结合实时盘面和消息面判断
