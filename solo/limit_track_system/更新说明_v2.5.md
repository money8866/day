## 🎯 本次更新内容

### 1. ✅ ST股票自动过滤
- **功能说明**：自动识别并过滤ST、*ST、退市等风险股票
- **实现方式**：通过Tushare获取股票名称，包含以下关键字的都被过滤：
  - `ST`、`*ST`
  - `退市`
- **测试结果**：已成功过滤 `*ST英飞`

---

### 2. ✅ 主线板块识别
- **功能说明**：筛选近20天涨停次数最多的前15个板块（主线板块）
- **判断标准**：
  - 统计近20天各行业涨停数量
  - 取前15个涨停最多的行业作为主线板块
  - 优先展示主线板块的股票
- **数据来源**：SQLite数据库中的历史涨停记录

---

### 3. ✅ 涨停后调整天数
- **功能说明**：显示从最后一次涨停到今天的调整天数
- **计算方式**：
  ```python

  ```
- **显示位置**：重点推荐和潜在候选股票的信息行

## 🔧 核心代码修改摘要

### 新增：ST股票过滤
```python
# 1. 过滤ST股票
stock_name = ts_code
is_stock = False
try:
    basic_info = pro.stock_basic(ts_code=ts_code)
    if basic_info is not None and not basic_info.empty:
        stock_name = basic_info.iloc[0].get('name', ts_code)
        name_upper = stock_name.upper()
        if 'ST' in name_upper or '*' in name_upper or '退市' in name_upper:
            is_stock = True
except:
    pass

if is_stock:
    print(f"  跳过ST股票: {stock_name}")
    continue
```

### 新增：主线板块识别
```python
# 2. 识别近20天主线板块
is_main_sector = False
try:
    conn = sqlite3.connect(DB_FILE)
    cursor = conn.cursor()
    
    # 查询近20天各行业涨停数量
    start_date_main = (datetime.strptime(trade_date, '%Y-%m-%d') - timedelta(days=20)).strftime('%Y%m%d')
    cursor.execute('''
        SELECT industry, COUNT(*) as zt_count
        FROM limit_stocks
        WHERE trade_date BETWEEN ? AND ?
        GROUP BY industry
        ORDER BY zt_count DESC
        LIMIT 15
    ''', (start_date_main, trade_date))
    
    main_sectors_list = [row[0] for row in cursor.fetchall()]
    conn.close()
    
    # 判断当前股票是否属于主线板块
    if industry and industry != '未知' and industry in main_sectors_list:
        is_main_sector = True
except Exception as e:
    print(f"  主线板块识别失败: {e}")
```

### 新增：调整天数计算
```python
# 3. 计算涨停后调整天数
adjustment_days = 0
if zt_history:
    last_zt_date = zt_history[0]['date']
    try:
        zt_dt = datetime.strptime(last_zt_date, '%Y%m%d')
        today_dt = datetime.strptime(trade_date, '%Y%m%d')
        delta = today_dt - zt_dt
        adjustment_days = delta.days
    except:
        adjustment_days = 0
```

## ⚠️ 注意事项

### 1. 关于主线板块
- 需要先运行 `full_backtrack.py` 生成历史数据
- 如果主线板块数量为0，说明历史数据不足
- 主线板块是动态变化的，每天会根据数据更新

### 2. 关于调整天数
- 调整天数是交易日差，不是自然日
- 一般建议关注调整3-7天的股票
- 调整过久（>15天）的股票需要谨慎

### 3. 关于ST过滤
- 过滤逻辑基于股票名称
- 如有新的退市风险标识，可在代码中补充
