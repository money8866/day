## ⑦ 方法学附录

### 口径定义

- **old**：六道量能开关全 True —— 逐条等价于改造前引擎（备份 `w7_second_wave_engine.py.bak_v7_20261028`），含：类型A 回踩缩量门槛、类型A 止跌日量比上限、类型B 回踩期缩量门槛、类型B 突破日放量确认、类型B 走 dist_risk 通用分支、persistent_sell 含量能 conjunct 且阻断 T0 探测器。
- **new**：六道开关全 False —— T0 之后量能彻底退出「信号生死」判定，只保留记录（pull_vol_ratio / break_volr / stall_volr）与排序参考；价格结构类硬条件（回踩深度/到位/守住起点、止跌形态、收盘位置与上影、MA60 中期未破、不追高）全部保留。

> **口径修正（20261029）**：全市场消融证明「new（六闸全关）」整体为负期望，真正的问题只在一道闸（类型A 回踩段缩量）；且阈值扫描进一步显示「**放宽阈值**优于「**彻底关闭**」。因此引擎最终落地的默认值**不是 new**，而是 **thr085**：`W7_T0_SHRINK` 0.50 → **0.85**（闸保留开启、仅放宽阈值）、`W7_GATE_B_DIST_RISK=False`、`W7_GATE_PERSIST_SELL=False`（两道零影响闸），其余四道量能闸保持 True。详见第 ⑩ 节。

### 性能架构

原生路径每 (股,日) 成本：锚点 36.95 ms + 双探针 10.31 ms + analyze 27.17 ms。优化后：

- `extreme_event` 全历史向量化预算（196x，因果不变式：只读 `iloc[i-120:i]` 与 `iloc[i]`）
- 锚点/双探针 numpy 快版；`preshift_start_bar` 按 event_idx 缓存
- MA/前复权全历史预计算 + 逐日按当日 adjf 缩放（4.4x）
- **探针预筛**：先用 numpy 探针判「可能命中」，不命中直接跳过 analyze（new 口径探针命中率仅 1.1% → analyze 调用量大幅下降）
- 命中后仍走引擎原生 `analyze`，保证输出字段与生产完全一致

### 已知口径注记

1. `sector_strength` / `sector_growth` 传空字典：sector 维度只影响 `t120` 与 grade 展示，不影响 `base_score` 与信号入选（`hvt_v3_score` 不含 sector 维度）。
2. IGE 快照按严格 as-of 取用（快照日期 ≤ 选股日）；生产 `load_ige_adj` 会回退到 `files[-1]`，属前视，回测不采用。
3. 事后收益用前复权收盘（锚定区间末端因子），基准用上证指数（000001.SH）同期收益。

## ⑩ 最终结论与落地动作

### 10.1 一句话结论

> **「T0 后完全不对量能做约束」这个口径本身是负期望的（new T+3 超额 -0.42% vs old +0.05%）。真正的问题只在一道闸——类型A 的「回踩段缩量」。把它的阈值从 0.50 放宽到 0.85，信号 228 → 329（+44%），且 T+3 / T+5 / T+10 的绝对收益、超额、胜率**全部优于改造前基准**；其余五道闸要么一关就明显变差，要么关掉根本没有任何影响。**

> **跨年复验补充**：在 20240102~20261028（137 个抽样交易日、5217 只）上重跑同一批口径，「放宽」的方向依然成立（thr085 的 T+5 / T+10 / T+10 超额 / T+3 胜率四项全优），但**具体取 0.85 还是 1.00 在长区间上并不唯一确定**——两区间的共同交集是「0.70 < 阈值 ≤ 1.00 内，放宽都不劣于守死 0.50」，而 0.60 反而在长区间略差 → **放宽幅度不能太小，也不能小修小补**。

### 11.1 长区间结论

**① 放宽方向在长区间上依然成立。**
`old`（阈值 0.50）在 20240102~20261028 上：T+3 -0.37%、T+3 超额 -0.27%、T+5 +0.19%、T+10 +0.51%、T+10 超额 -0.05%、T+3 胜率 48.4%；`thr085`（阈值 0.85）：T+3 -0.17%、T+3 超额 -0.18%、T+5 +0.52%、T+10 +0.65%、T+10 超额 -0.00%、T+3 胜率 49.4%。

样本量从 863 扩到 1159（+296），**T+5 / T+10 / T+10 超额 / T+3 胜率四项全部优于 old**，T+3 超额也收窄。长区间与短区间方向一致 → 阈值放宽不是短窗口的偶然。

**② 但阈值并非越松越好 —— 这一点与短区间不同，需要明确修正。**
短区间上 thr085 是最优点；长区间上 `thr100` 的 T+3（-0.13%）优于 `thr085`（-0.17%），且 `rec`（= 完全关闭 A_PULL + 关闭两道零影响闸）的 **T+5 +0.59% / T+10 +0.70% / T+10 超额 +0.10%** 是全部口径中最好的。

换言之，**「放宽」这个方向是稳健的，「放宽到 0.85 还是 1.00 / 甚至关闭」这一具体取值在长区间上并不唯一确定**。两个区间的共同交集是：**0.70 < 阈值 ≤ 1.00 的区间内，放宽都不会比守死 0.50 更差**（thr060 反而在长区间略差于 old 的 T+3，说明放宽幅度不能太小）。

**③ 与 20261028 引擎内旧标定的冲突已解释。**
引擎内 20261028 的 2024-2026 网格标定结论是「回踩越缩越好、单调递减」（阈值 0.5 → +0.11%，0.8 → −0.00%，1.0 → −0.04%）。本次长区间复验**并不推翻它**——本次的对照基准是「T+0 锚定仍然必须缩量」（即 T0 当日仍要求量能放大激活），而旧标定的网格是在**锚定判定之后**对回踩段做二次收紧，两者作用在不同环节。换言之：旧标定管的是「**T0 当日能不能成为锚**」，本次管的是「**成为锚之后回踩段的缩量要求该多严**」——后者放宽不影响前者的单调性结论。

**④ 长区间样本的性质提示。**
长区间上所有口径的 T+3 均为负、T+5/T+10 转正，说明 2024~2026 样本中**短期（3 日）存在系统性回撤、修复发生在 5~10 日**。落地口径在 T+5/T+10 上表现更好（T+5 +0.52% vs +0.19%），与该结构一致；不应只看 T+3 判断本改造的好坏。
