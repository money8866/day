# 2026-10-26 工作日志

## FinchX 5 分钟线可行性核查 + 封装工具

**问题**：FinchX 是否有 5 分钟 K 线。

**结论（源码 + 全量反射 + 实测三重验证）**：
- FinchX 3.1.1 全库 **61 个公开接口**（15 个 API 模块：articles/company/disclosure/financial/forum/
  fund_flow/fupan/hotlist/iwencai/market/news/reference/regulation/reports/sector）中，
  K 线相关仅 2 个：`fx.market.ohlcv`（**仅日线**，腾讯 newfqkline，_SERIES = day/qfqday/hfqday）
  与 `fx.market.equity_intraday` / `_5d` / `index_intraday` / `_5d`（**1 分钟粒度分时**，267 点/交易日）。
- **FinchX 本身没有 5 分钟 K 线接口**，但有两条可行路径拿到。

**路径 A（推荐）腾讯原生 mkline**：
- URL：`https://proxy.finance.qq.com/ifzqgtimg/appstock/app/kline/mkline?param=<symbol>,<period>,,,<count>`
- ⚠️ 必须用 `proxy.finance.qq.com`；`web.ifzq.gtimg.cn` 在本机网络下 502 Tunnel 失败。
- period ∈ {m1, m5, m15, m30, m60}；返回行 = [时间(YYYYMMDDHHMM), 开, 收, 高, 低, 量(手), {}, 换手率(‱)]
- **服务端固定 482 根上限**，count 传 640/1000/4000 都只返 482。历史深度 = 482÷每日根数：
  m1≈2 交易日 / m5≈11 / m15≈31 / m30≈61 / m60≈121。日期区间参数(start/end)无效，返回空。
- 字段单位标定：field5 = 成交量（**手**，×100 得股，与 FinchX 日线 volume 偏差 0.002%）；
  field7 = 换手率（**‱ 万分比**，用茅台流通股本反推 45.78 vs 原生 46.14，差 0.8% 来自均价vs收盘价）。
- 无复权。newfqkline 路径不支持分钟周期（传 m5 返回空，仅 version 键）。

**路径 B：FinchX intraday 自聚合**：
- 用 `equity_intraday_5d`（近 5 交易日）按 5 分钟切桶。
- ⚠️ 对齐口径（已逐根交叉验证，240 个共同时间戳收盘价偏差 **0.0000**）：
  桶标签 = 该桶**结束**时刻，1 分钟点 ceil 到下一个 5 分钟边界；
  首桶 09:35 含集合竞价共 6 点（09:30~09:35），其余各 5 点；15:00 桶吸收 15:00 后 25 个盘后点。
- 量=桶内分钟量求和；末根(15:00) 因含盘后点与原生差 4266 股，其余完全一致。

**产出**：`D:\mystock\finchx_minute.py`（可复用工具，含 CLI + to_symbol 转换 + 两条路径 + 错误处理）。

**实测可用性**：600519/000001/300750/688981/399001/510300/002594 全部 482 根正常；
北交所 bj430047 返回空（腾讯该源不覆盖北交所）。

**踩坑记录**：
1. `web.ifzq.gtimg.cn` 走代理 502，必须换 `proxy.finance.qq.com`。
2. 聚合时把 `minute`（分）当总分钟数用，导致所有点落进 09:30 桶 —— 用 `total = h*60+m`。
3. floor vs ceil 对齐差异巨大：floor 得收盘价偏差 10.06，ceil 得 0.0000。
4. 原生 m5 时间戳是**区间结束**时刻，不是开始时刻。
