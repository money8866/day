## 微信 ClawBot 主动推送失败根因定位与修复（延续 11-03 的 V10.7 收尾）

### 背景

本轮执行推送，连续失败：`HTTP 200 | errcode None | ret -2 | prepare failed`。

### 排查过程（逐层排除）
1. **凭证层**：比对 `credentials.json` 的 botToken 与 iLink 游标内嵌明文 →
   `61f53d8088c1@im.bot:060000c845642d2be6b2df7ed2754f097c449f` **逐字符一致**；
   `getupdates` 空 buf 返回 HTTP 200 无 errcode → **鉴权正常**。
2. **会话层**：`getconfig(ilink_user_id, context_token)` 返回 `ret=0` + typing_ticket；
   `sendtyping` status=1/2 均 `ret=0` → **token 有效、会话本身活着**。只有 sendmessage 失败。
3. **报文层**：从 `C:\Program Files\WorkBuddy\resources\app.asar` 里挖出官方实现
   （`WeixinApi` / `WeixinClawBotClient`），逐字段比对：
   - 官方 payload = `{from_user_id:"", to_user_id, client_id:"workbuddy-<ts>-<rand>",
     message_type:2, message_state:2, context_token, item_list:[{type:1, text_item:{text}}]}`，
     与本桥**完全一致**；
   - `base_info.channel_version` 官方为 `workbuddy-desktop-1.0.0`（本桥原用 `1.0.3`）。
4. **实测报文矩阵**：`channel_version` 试了 6 种取值、`client_id` 试了官方格式与桥格式、
   `message_type`/`message_state`/`from_user_id` 各试变体 → **全部 ret=-2**。
   → 报文不是原因。
5. **检索对照**：WebSearch 命中多个独立来源（CSDN 排障实录、cc-connect、hermes-agent、
   腾讯云开发者社区），结论一致：**`ret=-2 "prepare failed"` = iLink 会话未就绪**，
   要求用户近期主动给 bot 发过消息；且**限流惩罚窗口内每次重试都会加重惩罚**。
6. **本地日志印证**：WorkBuddy 主线程日志显示用户最后一次给 bot 发消息是
   **11-03 11:17:23**；而桥缓存的 token 是在 **16:35** 写入的（`acquired_at` = 缓存时刻，
   不是消息时刻）→ **假绿灯**：token 看着「0.1 天，很新鲜」，实际会话已超窗约 7 小时。
7. **决定性验证**：用户 11-04 00:00:48 给 bot 发一条消息后，用**完全相同的报文**
   推送 → **一次成功（HTTP 200 / ret=0）**。根因坐实。

## 修复 `_intraday_monitor.py` 的「预估全日成交额」算法

### 问题
原算法用 `amt_so_far * 240 / 已过交易分钟` 线性外推。但 A 股日内成交额呈 U 型分布
（早盘抢筹、午后清淡、尾盘放量），120 分钟（午盘）时累计已占全天约 **64.8%**，线性却只当 50%，
导致午盘严重高估全日。实测 11-04 11:30 半日 9309 亿 → 旧算法给 18464 亿（虚高约 30%）。
参考 `realtime_theme_monitor.py` 已用正确的 U 型曲线。

### 修复（D:/mystock/solo/_intraday_monitor.py）
- 顶部新增 `MARKET_AMOUNT_PROGRESS`（U 型累计占比曲线，对齐 realtime_theme_monitor）、
  `elapsed_trade_minutes_from_time(h,m)`、`intraday_amount_progress(minutes)` 三个自包含函数/常量。
- `analyze()` 内把外推段改为 `amt_est = amt_so_far / intraday_amount_progress(minutes)`，
  且**用 slot 名义时刻**算已过分钟（而非 `datetime.now()`）——定时任务在 11:30~13:00 波动时口径稳定，
  且午休期间已交易分钟固定为 120，不会被误判为午后。
- 同步更新 `_v107_intraday` 注释（"按已过交易时段折算" → "按日内累计占比 U 型曲线外推"）。

### 验证
重跑 `--slot 1130`：半日 9309 亿 → 预估全日 **14366 亿**（9309÷0.648），回归合理区间。
