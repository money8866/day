## 分析 solo/tushare_quant.py 选股算法（9199行/390KB）

文件定位：自选复盘主程序，产出「突破股池」Top10 + 每日报告/推送。

选股链路（六级漏斗）：
1. `get_market()` 全A（日线+total_mv），缓存至 cache_daily/market_{date}.csv
2. `strategy()`（L5303）核心形态：barslast(ZT) 定位涨停后 ztts∈[3,90]；TJ 回踩质量6条件；
   主板做突破(放量破前高+贴近MA5)、双创做低吸(回落3~15%+贴MA20+缩量)；
   P0 大周期门槛仅在 主升浪/趋势分≥60 时启用
3. `filter_by_top_themes(mode='resonance')`（L7138）注入共振系数 = 信号权重×阶段权重×延续权重，截断0.3~1.5
4. `calc_unified_stock_score()` V11（L3732）六维：突破质量25/资金行为24/位置安全18/基本面15/动量10/热度8；
   base_raw → 风险扣分(失败概率>35 按0.55、>50 再加0.45) → 主题层级系数(0.80~1.10) → S型软天花板
5. 风险过滤：`calc_20d_breakout_failure_risk`、剔除假突破、每主题只留失败概率最低3只、
   强势硬过滤(20日涨幅≤80% / 距MA20≤30% / 距MA10≥0%)
6. ChipAlpha + 二波形态 + Bull评分 注入 → 按整合评分排序 Top10

关键设计取向（读代码得出，供后续改动参考）：
- 结构优先于动量：动量权重仅10%，突破质量+资金合计49%
- 风险二次进入排序：失败概率不只是展示字段，直接扣分
- 主题层级天花板：非主线(<60) 上限78，核心主线(≥90) 上限97，防轮动股刷分
- 各阶段有回退链（V2主题→FUSION→V6/V8；JSON映射→降级名称匹配）

代码里有大量历史遗留：calc_dual_layer_score_v6/v7/v75 仍在文件内但主流程未调用；
`from sqlalchemy import true` 为无用导入。

## V11 评分模型量化审计（D:\mystock\_v11_audit.py 可复跑）

硬证据结论（供后续改造依据，勿重复论证）：
1. **软天花板函数有数学缺陷**（L4386-4392）
   - x=70 处不连续：左极限 70.00，右极限 72.88，瞬间跳升 2.88 分
   - 70~87 段斜率 >1（峰值约 1.05），是"放大"而非压缩，直到 x≈87 才真正斜率<1
   - 100→120 输入差 20 分，输出仅拉开 1.6 分，高分区彻底饱和
   - 结论：需要拉开的高分段饱和，不需处理的中分段反而制造跳变 —— 方向反了
   ⇒ 建议换 tier_cap*(1-exp(-x/s)) 或池内截面分位
2. **加权平均的分散化收缩**：sqrt(Σwi²)=0.4375，各维独立时 base_score 标准差仅单维 43.7%
   ⇒ 分数扎堆的根因在此，软天花板只是末端补丁
3. **维度有效话语权**（按实际波动 40 分、base_raw 跨度 60 分估算）
   突破质量16.7% > 资金16.0% > 位置12.0% > 基本面10.0% > 动量6.7% > 热度5.3%
   ⇒ 热度维度仅 5.3%，其"情绪过热-15"惩罚实际影响 <1 分，形同虚设
4. **同一风险三重计价**：ret20/ret_10 涨幅透支在 breakout_quality(-15)、penalty(-10)、
   failure_prob(+8→risk_penalty 放大) 各扣一次，系数各自独立拍定
5. **无截面标准化**：全为绝对阈值分档，regime 漂移时因子整体失效/饱和
6. **failure_prob 未校准**（启发式加减 clamp[10,90]）却当货币用于 risk_penalty 乘数，量纲错误
7. 其他：基本面缺失值填 50（数据可得性变 alpha）、无流动性/容量约束、无行业中性化、
   20日风险模型 horizon 与二波出场建议(5/8/20日)不一致

关键前提：report_daily/breakout_pool_snapshot_*.json 目前仅 1 天（20260904），
样本不足以做 IC/logistic 校准 —— **回测闭环未跑通是最大瓶颈，应优先补数据**

## V11.1 已实施（2026-09-07，用户确认后动手）

### 1. 资金行为反向
把 `capital_score = 50 + Σ` 拆成两个 delta 分别累加，按开关决定符号：
- `capital_delta_vol`（2a 量能趋势 + 2b 量价关系）← 可回溯，IC 实测 t=−4.31，已翻转
- `capital_delta_mf`（2c 同花顺资金流 + 2d 机构资金流）← 依赖外部接口无法回溯，**默认不翻**
- 开关：`CAPITAL_REVERSE_VOL=True` / `CAPITAL_REVERSE_MF=False`（两开关独立，后续补数据可单独验证）
- **同步翻转 `failure_prob` 的「量能强化」项**（vrr=5日均量/20日均量）。原逻辑"放量→失败概率降低"
  与反向后的 capital_score 自相矛盾，不一起翻会让模型内部打架。同一 `_vol_sign` 控制。

### 2. 换手率纳入为负向因子
- 新增全局 `POOL_TURNOVER_PCT` + `build_pool_turnover_pct(codes)`，在打分循环**之前**调用

- 开关：`TURNOVER_FACTOR_ENABLED=True` / `TURNOVER_NEGATIVE=True`
