## 执行要点
- Python 解释器固定路径：`C:\Users\kongx\AppData\Local\Python\bin\python.exe -u _intraday_monitor.py --slot <SLOT>`
- 脚本会输出完整的「实时读数 / 模块判定 / 仓位建议」三段，直接映射到消息模板字段即可。
