## MSW 全量运行（v1）暴露的验证层缺陷 + 修复 + v2 重跑（2026-10-21）

- v1 全量结果（修复前）：4730 只入池/3445 有信号/227 轮；IS 170 轮 +2.92%/轮（总 +57.4%），OOS 119 轮 -0.21%/轮（总 -5.7%）；组合 +1.6% Sharpe 0.185 MaxDD -44.7%；B&H +20.2%/MA趋势 +33.5%/动量 -19.8%/纯均值回归 +2.6%；成本 80bp 时消亡。判定 FAIL（①②③④ ✗）。
- 测试/审查发现 6 个缺陷（全部修复 + 回归测试，67/67 过）：
  1. parameter_stability 扰动静默失效：网格裸字段名 → _split_key 空节名 → 覆盖写进 cfg[''] → 9 组扰动全等于子集基线（354 轮/+1.71%）。修复：PARAM_SECTION 节映射 + apply_cfg_overrides 可测函数 + 不存在节告警。
  2. matched_control 零交易：MSW 事件限制到不相交对照代码 → 0 交易。修复：安慰剂计时（placebo timing）——移植交易序列到对照股、用对照股自身价格/涨跌停/停牌/ATR 重模拟（load_bars_for_codes + build_placebo_events）。冒烟：32 轮 -2.27%/轮、总 -10.7% vs MSW -1.5%。
  3. 第三处日期格式坑：_momentum_events 调仓日过滤 + 指数区间过滤用带横杠日期比 YYYYMMDD 文本 → 静默丢整个 2026 年。修复：norm_date。
  4. liquid_codes「近一年」变全历史（同格式坑）。修复：compact 日期 + end 上界。
  5. walk_universe 缓存驱逐键不匹配（带横杠 vs 紧凑）→ 驱逐从未生效，全量运行 ~700MB 内存驻留。修复：键一致 + load_bars_for_codes 逐股驱逐。
  6. run_msw summary JSON 对 index_buy_hold 扁平结构特判。
- 新增行走缓存 --cache-walk/--use-cached-walk（配置哈希校验），msw/out/walk_cache_full.pkl。
- v2 全量重跑 2026-10-21 04:27 后台启动（GMTNeo），日志 msw/out/full_run_v2_*.log，预计 2.6-3h。

## MSW v2 全量重跑完成 → 最终判定 FAIL（2026-10-21 07:24）

- v2（修复后全量，2h57m）：本体数字与 v1 一致（227 轮/IS +2.92%/OOS -0.21%/总 +1.59%/Sharpe 0.185/MaxDD -44.7%），但验证层全部有效化。
- 有效化证据：参数扰动 6 组各异（+1.448%~+2.064%，符号一致 6/6）；matched_control 安慰剂计时 1110 对 → -6.47% vs MSW +1.59%（选股 alpha ~+8pp，计时本身 ≈ 盈亏平衡）；动量基线修正为 -59.5%（v1 丢 2026 年误报 -19.8%）；指数 +22.6%。
- 消融关键：no_vol_position 唯一转负（-0.39%/轮）→ ATR 风险预算仓位是承重组件；no_trend_filter 轮数 +73% 但均值降 → 以量换质；no_quality_score/no_fundamental 在流动性子集不绑定；with_regime_filter 无正贡献。
- **判定 FAIL（2/6：⑤⑥过；①②③④败）**：OOS 期望 -0.21%、IS/OOS 分裂、Sharpe 全面劣于 B&H(0.437)/MA趋势(0.543)、剔除 Top5% 后期望 -0.59%（Top5% 贡献 439% 净收益）。
- 交付：msw/out/ 下 11 类文件 + msw_validation_report.md（Q1/Q2/Q3 数据驱动）+ regenerate_report.py（缓存+CSV → 2 分钟再生报告）。测试 67/67 过。
- 结论：V1 不作为可实盘策略交付；唯一稳健正贡献是选股维度。行走缓存 msw/out/walk_cache_full.pkl 可复用（--use-cached-walk）。
