### 关键设计决策
1. **量价四要素**：环比成交额变化率 / 相对 5 日均变化率（均额不含当日）/ 指数涨跌幅 / 上涨股票占比。
   「放量上涨」必须三要素齐备；指数涨但广度不足 → 「放量滞涨（指数涨、个股分化）」。
   2026 全年有 **9 天**属放量滞涨（旧口径会误判为放量上涨）。
2. **S4 卖压衰减确认**五项：跌停连续下降 / 卖压连续衰减 / 广度改善 / 涨停跌停比不恶化 / 无局部风险恶化。
3. **S5 反弹确认**五项：广度持续改善 / 跌停明显下降 / 涨停跌停比改善 / 量价与指数方向匹配 / 主线持续性赚钱效应。
4. **STRUCTURAL_ALPHA_EXCEPTION**：仅 S3/S4/S6 允许。入池五项（连续强态≥15日、20日超额≥10%、
   60日趋势未恶化、成分股广度达标、排除单权重股拉升）+ 出池复核四项（成分股业绩基本面、
   行业内上涨家数占比、领涨股趋势、成交额持续性）。**不得突破市场状态仓位权限**。
5. **仓位语义分离**：目标仓位 / 建议区间 / 仓位硬上限 / 主动加仓权限 / 满仓授权 五者分列；
   目标仓位是环境参考值，不是必须持仓比例（S4 目标 20% 但无合格标的时可持 0% 现金）。
6. **状态门控**：S4 进入需卖压衰减 PASS、S5 升级需卖压衰减+反弹 PASS；UNKNOWN 不算通过；
   门控**只收紧不放宽**仓位（落点状态权限必须 ≤ 原状态）。

### 两个踩坑（重要）
- **严格连续口径会把 V 形修复日否掉**：跌停序列 [51, 95, 10]（10/29→10/30→11/02）
  在「连续2日下降」下要求 51>95>10 → 不成立，于是「跌停 95→10、上涨占比 16%→85%」
  的典型卖压衰减日反被判 FAIL。改用 **decay 口径**：今日相对昨日改善 **且** 相对前日也改善。
  两种口径都在配置里可切（`dt_decrease_mode` / `breadth_improve_mode`），测试都覆盖。
- **门控不得放大仓位**：最初 G1 被否决时回退到 `prev_state`，若 prev_state=S2(30%) 而
  base=S4(20%)，反而把仓位从 20% 提到 30%。修复：落点状态权限必须 ≤ 原状态，否则维持原状态只做标注。
