# 每日盘后选股程序

**策略**：缺口突破 + 缩量 + 大盘回调
**回测**：5541 只 × 343 交易日（2025-01-02 ~ 2026-06-05），均收益 +2.98%，胜率 52.7%

---

## 用法

```bash
# 盘后跑（收盘 15:00 之后）
python daily_picker.py

# 只看大盘能不能开仓（几秒钟出结果）
python daily_picker.py --no-trade

# 导出 JSON
python daily_picker.py --json pick.json
```

输出 `pick.json` 便于接入其他系统。

## 选股逻辑

```
信号    当日最低价 > 上一交易日最高价（真实向上跳空缺口）
        缺口幅度 0.8% ~ 9%
条件①  量比 < 1.5        （缩量，阈值经档位回测校准）
条件②  中证1000 20日涨幅 < 0%  （大盘回调期）
```

**条件②不满足直接空仓**，这是硬闸门。

### 为什么是「缩量」

回测发现**放量是负向信号**（这是反直觉的）：

| 缺口幅度 | 缩量（量比<1.5） | 放量（量比>3） |
|---|---|---|
| 0.8~2% | +2.03% | +0.04% |
| 2~4% | +2.58% | +0.47% |
| 4~9% | +6.72% | −0.28% |

放量说明抢跑资金已透支未来，缩量才说明抛压小、锁定度高。

### 量比阈值从 2.0 收紧到 1.5 的依据

细分档位后，收益与胜率随量比**单调递减**，说明原定 2.0 过宽：

| 量比区间 | 笔数 | 均收益 | 胜率 |
|---|---|---|---|
| 0~0.6（极缩） | 848 | **+8.89%** | 59.8% |
| 0.6~0.9 | 1019 | +2.61% | 58.1% |
| 0.9~1.2 | 1525 | +2.44% | 57.4% |
| 1.2~1.5 | 1277 | +2.18% | 52.2% |
| **1.5~1.7** | 636 | **+1.38%** | **41.2%** |
| 1.7~2.0 | 792 | +0.75% | 39.1% |

**量比 < 1.5：+3.58% / 胜率 56.6%**；**1.5~2.0：+1.03% / 胜率 40.1%**。

极缩量档（<0.6）在六个独立时段**全部最优**，中位数 +4.10% 为正，
去除最高最低各 1% 后仍 +8.67%（不是靠极端值撑起）。

### 为什么是「当日直接追」而不是「等回踩」

回测对比：当日直接追 **+1.88%** vs 等回踩 **+1.84%** vs 挂单越靠近下沿越差。
A 股缺口形成后几乎不回头，等浅回踩等于用更差的价格买更少的机会。

## 输出说明

每只标的包含：

| 字段 | 含义 |
|---|---|
| `gap_pct` | 缺口幅度 |
| `vol_ratio` | 量比（当日量 / 前20日均量，不含当日），<1.0 为最优区间 |
| `prev_high` | 缺口下沿 = 止损基准 |
| `stop` | 止损位 = 下沿 ×(1−1.5%) |
| `target_1r` | 1 倍风险对应的目标价 |
| `score` | 综合打分（0~100） |

打分权重：量比 45 分（越低越好）+ 缺口 25 分（1.5~4% 最优）+ 流通市值 20 分 + 硬板 10 分。

量比档位标注：`极缩量(最优) <0.6` / `很缩(优) <1.0` / `缩量(良) <1.2` / `偏缩(弱) <1.5`。
**低于 1.0 的标的应优先考虑。**

## 执行纪律

1. **次日开盘买入**（回测结论：当日直接追优于等回踩）
2. **止损恒定在缺口下沿 −1.5%**，跌破即离场，**不摊平**
3. 持有 8 个交易日；达 1R 减半仓，余仓转移动止损
4. **单笔风险敞口 ≤ 总资金 1%**，据此反推股数
5. 单日最多 3 只
6. 若次日大盘低开 >1%，全部取消

## 排掉的坑（都实测踩过）

1. **腾讯日线最后一根就是当日**（盘后），不是上一交易日。
   取 `bars[-1]` 当昨高会让缺口恒为负、全部标的被误杀。必须用 `bars[-2]`。
2. **均量不能含当日**，否则量比被低估。须用 `bars[-21:-1]`。
3. **新浪快照的 `settlement` 是昨收不是昨高**。用昨收算缺口会高估，
   必须拉日线取真实昨高复核。
4. **`Pick` 是 dataclass**，排序须用 `x.score`，写成 `x["score"]` 会抛
   `TypeError: 'Pick' object is not subscriptable`。
5. **新浪 `amount` 单位是元，`nmc`（流通市值）是万元**，搞错会算出 834 万亿。
6. **必须排除 ETF/LOF/基金**。它们的跳空来自套利折价，不是资金博弈。
   双重过滤：名称关键词 + 代码段（51/56/58/15/16/50/17 开头）。
7. **涨停股买不到**，须剔除 |涨幅| > 9%。

## 已知局限

- **未做 ST 动态剔除**：新浪快照有名称，ST 已排除，但盘中更名的新 ST 可能漏过。
- **未计滑点与冲击成本**：回测收益 +2.98%，扣双边成本（约 0.2~0.3%）后约 +2.7%。
- **样本偏多头**：2025-01~06 为普涨期。2026 年数据显示策略在弱市里优势钝化
  （2026Q1 仅 +0.74%），熊市中"缩量"可能意味"没人接"而非"锁筹"。
- **无 walk-forward**：参数在全样本上确定，存在过拟合风险。
- 大盘闸门用的是中证1000，若风格切换到大盘蓝筹可能不适用。
