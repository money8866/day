# A股「跳空突破 + 板块共振」盘后选股策略

盘后选股程序。产出 T+1 候选池与止损位，纯规则化，无未来函数。

## 为什么只做这一个模式

跳空策略有四类可交易形态（突破缺口 / 持续缺口 / 普通震荡缺口 / 衰竭缺口），
但落到 A 股「盘后选股」这一个动作上，只有「突破缺口 + 板块共振」同时满足三件事：

| 要求 | 原因 |
|---|---|
| 止损位可定义 | 缺口下沿 = 前日最高价，是真实结构位，赔率可控 |
| 标的池可枚举 | 涨停池天然把全市场 5000 只压缩到 50~80 只，无需全市场扫描 |
| 有正交确认源 | 板块共振提供个股之外的独立信号，不必依赖 K 线形态单点判断 |

其余三类要么需要做空（A 股散户无法融券做空），要么需要日内高频执行（T+1 不可实现），
要么胜率不足以覆盖滑点。缺口回踩模式赔率虽好，但属盘中模式而非盘后模式。

## 用法

```bash
# 盘后跑，默认取最近交易日
python gap_strategy.py

# 指定交易日
python gap_strategy.py -d 20260930

# 只做情绪体检，不选股（收盘后快速判断今日能否出手）
python gap_strategy.py --no-trade

# 取前 5 名并导出 JSON
python gap_strategy.py --top 5 --json out.json
```

## 六道关卡

```
第一关· 情绪闸门 ─── 总开关，不通过则当日空仓
   ├ 炸板率 ≤ 30%
   ├ 最高连板 ≥ 3 板
   ├ 核按钮（昨日涨停今日跌停）< 5 只
   └ 周期阶段 → 仅「发酵期」允许开仓
              冰点/高潮/退潮 一律空仓

第二关· 硬过滤（不可交易项一票否决）
   ST/退市 · 成交额 2~60 亿 · 流通市值 ≥ 30 亿
   连板 ≤ 4 板 · N天M板中 N ≤ 4（防筹码断层）
   剔除一字板（买不到，开板即集中抛售）· 炸板 ≥ 2 次
   封单比 ≥ 0.08（锁仓意愿硬门槛）

第三关· 突破缺口 ── 收盘价大幅超越近 20 日箱体上沿
第四关· 量能验证 ── 1.3 ≤ 量比 ≤ 8（排除真空跳空与天量派发）
第五关· 板块共振 ── 题材内涨停 ≥ 2 家（一票否决项）
第六关· 综合打分 ── 满分 100，输出 Top N
```

### 打分权重

| 维度 | 分值 | 说明 |
|---|---|---|
| 板块共振 | 30 | 共振家数 + 龙头加成 |
| 封单质量 | 20 | 封单比分位 + 封板时间 |
| 个股地位 | 20 | 连板高度 + 龙头 + 是否硬板 |
| 量能 | 15 | 是否落在健康放量区间 |
| 缺口强度 | 15 | 超越箱体幅度 |

## A 股口径的重要修正

**1. 「全天不回补」不适用于 A 股。**
美股是收盘竞价定价，跳空后不回补是强势信号。但 A 股涨停为盘中封板、
开板回落后收盘仍封在最高价附近，全天最低价几乎必然跌回前日最高价之下。
若照搬「最低价 > 前日最高价」判定，全市场 0 命中（实测 2026-09-18/24/30 全部为空）。

A 股「跳空突破」的等价定义：**收盘价大幅超越近 20 日箱体上沿**，
即资金用收盘价重新定价。缺口下沿取前日最高价。

**2. 封单比阈值来自实测分位数，不是网络流传值。**
真实分布（2026-09-16 ~ 09-30 实测）：中位数 0.10~0.15，p75 0.20~0.30。
网络文章常称「≥2 为合格」，与真实量级差一个数量级，照搬会导致全市场归零。
极高值（>1）通常是一字板全天封死、当日成交额极小所致。

**3. 封单比极值需警惕而非加分。**
封单比 = 封板资金 / 成交额。一字板当日成交额接近 0，比值可达 35，
此时该指标无意义——故一字板在第二关已被剔除。

## 参数调优

所有阈值集中在 `gap_strategy.py` 顶部参数区：

```python
SENT  = {...}   # 情绪闸门阈值
HARD  = {...}   # 硬过滤
GAP   = {...}   # 缺口形态
VOL   = {...}   # 量能
SECTOR= {...}   # 板块共振
SEAL  = {...}   # 封单质量
W     = {...}   # 打分权重
```

回测调优时**只改参数区，不动逻辑**。

## 明日执行纪律（程序已输出）

1. **竞价确认**：次日高开 1%~5% 且竞价量放大，方可介入；低开或竞价清淡则放弃。
2. **止损**：跌破缺口下沿（已含 0.5% 缓冲）无条件离场，**不摊平**。
3. **目标**：+1R 减半仓，余仓用 1×ATR 移动止损追踪。
4. **板块联动**：若次日板块内龙头低开闷杀，全部候选一律取消。
5. **仓位**：单日最多 2 只，总仓位不超过 50%。

## 已知局限

- **无回测模块**。当前为规则化选股，胜率与赔率尚未验证；参数来自
  公开实证区间 + 实测分位数，未经本地历史样本检验。
- **不含 T+1 竞价数据**。程序不预判次日竞价强度，该项须盘中人工确认。
- **题材字段依赖东财 hybk**，为东财自有分类，与市场主流题材口径可能有差异。
- **腾讯 K 线不含成交额**，量能验证只能用成交量（手），与成交额口径存在差异。
- **仅支持沪深**，北交所需改用通达信盘后包。
- **腾讯 K 线限流**：单入口约 600 次后返回空，程序已内置三入口自动切换 +
  冷却机制，但盘后全市场扫描仍有耗时。
