# 跳空缺口跟踪 · 回踩买点策略

全市场扫描向上跳空缺口，跟踪回踩确认买点。**与涨停股无关。**

## 定位

用户要的是「跳空后跟踪找买点」，不是「涨停股选股」。本模块是为此重写的版本。

| 模块 | 驱动源 | 判定对象 | 用途 |
|---|---|---|---|
| `gap_trade.py`（本模块） | 全市场 | 真实跳空缺口 | 跟踪回踩买点 |
| `gap_strategy.py` | 涨停池 | 收盘突破箱体 | 打板/涨停策略（另一套） |

## 核心流程

```
1. 粗筛   全市场快照 → 筛出「最低价 > 昨收」或「开盘跳空 >1%」的候选
2. 回溯   逐只扫描近 N 日内的所有向上缺口
3. 分级   突破缺口 / 持续缺口 / 衰竭缺口
4. 跟踪   判定状态 → 输出买点、止损
```

## 缺口定义（严格）

**当日最低价 > 前一交易日最高价** —— 两日价格区间完全不重叠。

这是唯一无歧义的跳空定义。注意基准必须是**前一日最高价**，不能用昨收：
昨收 ≤ 昨日最高价，用昨收会**系统性低估缺口**，导致明明跳空的票被漏掉
（实测用昨收代理时，200 只候选筛出 0 个缺口）。

## 买点逻辑

| 状态 | 条件 | 动作 |
|---|---|---|
| **回踩买点** | 现价在缺口下沿上方 0~2% + 缩量 | 分批建仓 |
| 回踩但未缩量 | 到位但量能未萎缩 | 等缩量再动 |
| 未回踩 / 远离 | 溢价 > 2% | 等回踩，不追高 |
| 已跌破失效 | 收盘跌破下沿 | 放弃 |
| 机会成本过高 | 缺口 > 5 日未回补 | 换标的 |

**止损恒定在缺口下沿下方 1.5%**，跌破即离场，不摊平。

## 分类阈值

| 类型 | 缺口幅度 | 处理 |
|---|---|---|
| 突破缺口 | ≥ 2.0% | 参与（强势，趋势启动） |
| 持续缺口 | 1.2% ~ 2.0% | 参与 |
| 衰竭缺口 | ≤ 1.2% | **剔除**（易回补，是见顶信号） |

## 用法

```bash
# 实时模式（盘后跑）—— 买点信号在这里产生
python gap_trade.py

# 回溯更多天数
python gap_trade.py --hist 15

# 历史模式（仅支持近期日期）
python gap_trade.py -d 20260930
```

## 为什么买点常常为 0

**这不是 bug。** 强���市里缺口形成后价格继续走高，根本不回踩。
实测 2026-09-30 附近：14 个有效缺口，溢价中位数远超 2% 回踩带，买点为 0。

回踩买点天然是**逆势信号**，只在市场调整时出现。程序的价值在于：
平时告诉你「没有，别动手」，调整时告诉你「这几只可以看了」。

若长期跑出 0 买点不意外，但**连续多次为 0 且市场确实在跌**，应检查回踩带参数是否过严。

## 数据源与限制

| 项 | 说明 |
|---|---|
| 全市场扫描 | 新浪 Market_Center（东财 `push2.eastmoney.com` 在本机网络被拦） |
| 日K线 | 腾讯，三入口自动切限流 |
| 涨停池 | 东财 push2ex（历史模式候选池用） |

**已知限制**：
- 东财涨停池只保留近期约一个月数据，历史回溯仅支持近期日期
- 实时涨幅榜不能用于历史日期（标的与日期不匹配）
- 一字板缺口已剔除（买不到，回踩无意义）
- 只支持沪深，北交所需通达信盘后包
- 无回测模块，参数未做历史样本检验

## 调试踩过的坑

1. **新浪 `amount` 单位是元**（不是万元），`nmc` 单位是万元。搞错会算出 834 万亿成交额。
2. **回溯循环边界**：`count` 拉了 N 根但循环遍历全部，会扫出超出回溯范围的缺口
   （`--hist 10` 却输出 28 日前的缺口）。须 `start = max(1, n-1-lookback)`。
3. **连续一字板要剔除**：新华传媒 6 连一字，缺口永不回踩，买点无法成交。
4. **`push2.eastmoney.com` ProxyError**：换新浪 `Market_Center`。
